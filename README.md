# Rockrobot3

Toward embodiment. RockRobot3 is a desktop companion robot: it listens, speaks, and interacts.

## Get Involved

The project is in its early stage. See [docs/architecture/architecture.md](docs/architecture/architecture.md) for the architecture and [docs/status.md](docs/status.md) for where the build actually stands.

Discussions and contributions are welcome — Issues are the front door.
