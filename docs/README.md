# docs —— 文档索引（四档）

docs/ 按**变更频率与读者动作**分四档：`architecture/` 半年一变，读者要的是"为什么这样切"；
`reference/` 随代码同批变，读者要的是"照着写、照着调"；`process/` 是协作契约，读者要的是
"提交前对什么"；`status.md` 是快照，每次里程碑收口整篇重写。

**每类内容只有一个权威落点**，其余文档引用它、不复述它——复述是漂移的源头（架构文档 §5
曾因把设计期草图当既成事实书写而整段重写）。

必然漂移，所以只留一份。
