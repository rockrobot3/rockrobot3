## 1. 范围与阶段

本档覆盖 **ADR-0015 三步走中的第 ② 步（过桥）**：RK3566 核心板 + 自绘底板。
第 ① 步（ZERO 3 成品板）无硬件设计工作；第 ③ 步（量产全自研 SBC）在本档 §3 核对单
与 §5 电源树验证结论之上另立版本，本档不预写。

| 项 | 裁定 |
|---|---|
| 主控 | RK3566（核心板形态，DDR/eMMC/PMIC 由核心板厂背书） |
| 底板信号等级 | **全低速**（I2S/SPI/I2C/UART/PWM/GPIO/USB2/SDIO）——任何 >100MHz 走线锁死在核心板内 |
| 底板尺寸 | 按 0.5L 腔体反推，目标 ≤ 70×70mm（核心板 + 连接器 + 电源区） |
| 成本目标 | 板级 BOM：样机 ≈200 元、1k+ 量 ≤150 元（达成条件见 §10，不承诺） |

| C4 | **PMIC 型号与 suspend 行为**：内核 6.6 mainline 下 `mem` 深度睡眠电流实测值（厂商或自测） | 待机 <1W 预算的大头；PMIC 不支持 mainline 驱动 = 直接淘汰 |

## 4. 底板系统框图

```
                        ┌─────────────────────────────┐
 12V/2A DC ──► 防反接 ──►│ 电源区                      │
                        │  SY8801 降压 5V（主）        │
 USB-C ◄──OTG──┐        │  3.3V LDO（低 Iq，待机轨）   │
 (烧录+调试)    │        │  PMOS 整板断电路径 T1        │
              │        └──────┬──────────────────────┘
              │               │ 5V / 3.3V
        ┌─────▼───────────────▼──────────────────────┐
        │            RK3566 核心板（外购件）           │
        │   SoC + LPDDR4 + eMMC + RK809(PMIC+codec)   │
        └─┬────┬────┬────┬────┬────┬────┬────┬───────┘
     I2S0 │    │SDIO │I2C0 │I2C1 │PWM×4 │SPI0 │USB2 host
          │    │    │    │    │    │    │    │
     ┌────▼┐ ┌─▼──┐ ┌▼───▼┐ ┌▼────▼──┐ ┌▼────▼─────┐
     │数字麦│ │WiFi│ │电量计│ │舵机接口 │ │屏 FPC +   │
     │×2   │ │BT  │ │CW2015│ │4ch 3P  │ │LED×1      │
     │+功放│ │模组│ │+I2C  │ │(独立5V  │ │(2.4" SPI) │
     │NS4150│ │    │ │hub  │ │ 开关T2) │ │           │
     └──┬──┘ └────┘ └──┬───┘ └───┬────┘ └───────────┘
        │喇叭          │         │
                   ┌───▼─────┐   │
        18650×2 ──►│充电+防护 │◄──┘ (I2C: env/imu 挂 I2C1 hub)
                   │IP2326类 │
                   │低Iq选型 │
                   └─────────┘
```

要点：**两条独立断电轨**——T1（PMOS）切核心板全部供电（**深睡/关机态**：核心板完全断电，
只留 3.3V 待机轨上的 RTC 与电量计），T2 切舵机电源（舵机保持通电会漏电且抖动）。
**"待机"须分清两级**：T1 断 = 深睡/关机；T1 通 + SoC `suspend` = **工作待机**，
后者才是本档 <1W 目标的执法态（§5.2）。电量计与 RTC 挂常电小电容，掉电不失时间戳。

## 5. 电源树与功耗预算

### 5.1 电源轨

| 轨 | 来源 | 电压 | 峰值负载 | 深睡负载（T1 断） | 备注 |
|---|---|---|---|---|---|
| VIN | 18650×2（6.0–8.4V） | — | — | — | 防反接 + TVS |
| 5V 主 | SY8801 降压 | 5.0V | ~2A（舵机堵转裕量） | 关断（T1） | 舵机独立开关 T2 常开于此轨 |
| 3.3V 待机 | 低 Iq LDO（Iq ≤15µA） | 3.3V | ~500mA | RTC+电量计 | **不得**用大 Iq LDO 凑合 |
| 核心板电源 | RK809（核心板自带） | 多路 | — | 0（T1 断，整板断电） | 底板不重复设计电源树；工作待机（suspend）电流由 C4 实测值定，见 §5.2 |
| 充电 | IP2326 类（选型判据：待机 Iq ≤20µA 或可 EN 关断） | — | 2A | 见 §5.2 | 通用满载好、Iq 大的方案直接淘汰 |

### 5.2 工作待机 <1W 预算分解（判据：实测，不是估算）

**执法态唯一 = 工作待机（`suspend`）**：T1 导通、SoC 挂起、WiFi 休眠、麦克风低功耗守听。
深睡/关机（T1 断）功耗远低于 1W（只留 RTC+电量计），**不参与本表**。任何"待机"读数先声明
是哪一级，避免两条路径读出不同数字。

| 项 | 预算 | 执法方式 |
|---|---|---|
| 核心板 suspend（RK809 全轨关） | ≤300mW | 样片实测（C4） |
| 充电/防护/电量计待机 | ≤100mW | 选型 Iq 表 + 实测 |
| WiFi 模组休眠 | ≤150mW | RTL8723DS 唤醒挂起模式 |
| 底板漏电（上下拉、LED 驱动、T1/T2 残流） | ≤100mW | layout 审查 + 实测 |
| 舵机轨（T2 关断后） | ≈0 | 关断即物理断路 |
| 裕量 | ≥350mW | — |
| **合计** | **≤1000mW** | **首版验收：直流电源串电流表，`rr3-ctl` 触发全系统 suspend 后读数** |

任何一项实测超预算 → 不进入下一版 layout，先归因（这是 ADR-0015 裁定 3-2 的落地）。

## 6. 引脚分配预算表（核心板 → 底板 → 能力格）

一格一主控制器；引脚级映射（具体 GPIO 编号）随核心板选定后回填，本表先钉**控制器级预算**。
`格位`列对 [contracts/slots.toml](../../contracts/slots.toml)，`模块`列对 architecture.md §5。

| 底板功能 | 控制器 | 能力格 | 模块 | 预算依据 |
|---|---|---|---|---|
| 数字麦×2 + RK809 内置 codec | I2S0 | `audio.capture` | rr3-sense | 单路够用；I2S1 留外置 codec 退路（C5 不满足时启用） |
| 功放 NS4150 → 喇叭 | codec 输出（模拟） | `audio.playback` | rr3-interact | 走 RK809 HPOUT，不经 I2S 第二路 |
| WiFi/BT | SDIO1 + UART(BT) | `net.wifi` `net.bt` | rr3-connect | 核心板自带模组则本行转为验证项 |
| 表情屏 2.4" | SPI0（含硬件 CS）+ DC/RESET/背光使能 3×GPIO | `ui.face` | rr3-interact | RGB 并屏（3.5" 选项）**不选**：占 GPIO 太多且 mainline 面板驱动风险高 |
| 灯效 LED | PWM0 ×1（RGB 单路则 ×3） | `act.led` | rr3-act | |
| 舵机 ×4 | PWM1~4 | `act.servo` | rr3-act | 数量待定项（§12-O1）；50Hz 硬实时归反射环（ADR-0007） |
| 电量计 CW2015 | I2C0 | `power.battery` | 基座转发 | base 格通道（ADR-0012 裁定 1 注记） |
| 充电状态 | 1×GPIO(STAT) + I2C0 | `power.charger` | rr3-power | |
| IMU QMI8658 | I2C1 | `sensor.imu` | rr3-sense | INT 脚 1×GPIO（唤醒事件） |
| 温湿度/光感 | I2C1 | `sensor.env` | rr3-sense | 与 IMU 共总线，地址无冲突即并挂 |
| maskrom/烧录/调试 | USB2 OTG → USB-C | — | — | C1 的板端落点；CC 脚 5.1k 下拉为 device 模式 |
| 备用 | UART2（调试壳）、2×GPIO（按键/恢复出厂） | — | — | 工厂恢复入口（architecture §7） |

## 8. 布局与机械约束

1. **被动散热**（RK3566 无风扇运行是 ADR-0001 体积约束的推论）：核心板屏蔽壳朝外壳
   铝面方向，中间导热垫；舵机电源区与核心板对角布置（热源分离）。
2. 麦克风远离 DC-DC 与喇叭（≥15mm），I2S 走线包地。
3. 板对板连接器选型须保证核心板与底板**可手拆**（返修），不用焊接式。
4. 0.5L 腔体内板形随外壳定版，本档只钉"≤70×70mm + §7 连接器开孔清单"两条接口约束。

## 9. 设计规则清单（layout 审查逐条过，一票否决）

- R1 上电时序：核心板 VIN 经 T1 软启动（RC 延时），禁止舵机 5V（T2）与核心板同时上电冲击
- R2 全接口防反接（电池 J4 必须串防反器件，不依赖连接器键位）
- R3 VBUS/DC 输入口 TVS；舵机 SIG 脚串 100Ω（ESD 与振铃）
- R4 I2C 全总线上拉 4.7k 集中放底板（不依赖器件内部上拉）
- R5 每电源脚去耦按核心板厂 reference 表照抄，一颗不落
- R6 maskrom 进入路径全程可测：J1 → OTG 差分 → 核心板，中途无 ESD 器件寄生影响 D±
- R7 复位/恢复出厂按键加硬件去抖（RC），不依赖软件

## 11. 首版验收测试计划（bring-up 死顺序，前项不过不测后项）

1. **电源**：不焊核心板，T1/T2 逻辑验证 + 各轨电压 + 3.3V 待机轨 Iq 实测
2. **烧录**：核心板插座，J1 进 maskrom，烧保底轨镜像（ADR-0013 buildroot 轨）→ 起 rrd
3. **枚举**：`dmesg` 对 §6 表逐行核对（ALSA 设备、SDIO WiFi、I2C 扫描地址、PWM）
4. **音频闭环**：ADR-0007 延迟判据过 + **VAD 误触率实测**（C5 的 codec 判定数据，回填 §12-O2）
5. **工作待机**：`rr3-ctl` 触发 suspend（T1 导通态），电流表读数 ≤1000mW（§5.2 判据）；
   另测深睡（T1 断）读数，只登记不设阈（远低于 1W）
6. **舵机**：反射环 1kHz 命令流下 T2 通断 ×1000 无复位
7. **OTA**：A/B 双槽升级 + factory recovery 全链路（复用 ZERO 3 用例集，换板重跑）
