# 模块设计框架 v1.1（本集所有模块册必须照此填写）

> 立这份框架的理由：**上一版模块册是"说明文"，读完写不出代码。** 框架版要求每个模块交同样的 12 件
> 工件，且每件都可核对——签名照抄仓内现物、目标签名以 `→` 标注、时序数字必须有来源、降级逐格逐因分开。
> 规矩（v1.1 订正，与六册实填对表后改）：**推测值**——没有来源的数、没有证据的行为——只允许出现在 §11；
> 而 §4/§6 里"**未实测**""**后端未实装**""**板上未证**"这类**缺口标记**是必须写的（降级矩阵天然要有一列讲
> 实装状态），但每条都要指回 §11 的某一条敞口，不能就地停在"未实测"三个字。
> 其余任何一节出现推测值即视为该册未完成。

## 十二节与各自的完成判据

| 节 | 必须交的工件 | 完成判据（别人怎么查你） |
|---|---|---|
| §0 单元身份证 | 格集 / 件集 / 主题面 / 句柄 / 参数文件 / 健康三数 / 资源三数，逐项指回 `module.toml`、`config.toml` | 任一格指不出件、任一主题指不出发布点即未完成 |
| §1 件契约表 | 每**公开符号**一行：签名（照抄现状）→ 目标签名、输入、输出、**状态持有与否**、失败语义（业务 error / 传输 exit(1)），并标明它是**件面导出**（`<name>.rs` 的 re-export 白名单里）还是**只在 `mech` 内 `pub`** | 缺任一 `pub` 符号即未完成；有 `→` 的必须说明为什么改；**"内松外紧"（mech 里 pub、件面不导出）必须逐条点名并立工单**——要么升为契约面，要么降 `pub(crate)`，不许停在中间态（sense S-6 就是这么发现的） |
| §2 状态机 | 有状态的件交枚举 + 转移矩阵 + 不变式 + "非法输入往哪个方向收敛" | 无状态的件写"无状态"，不许留空 |
| §3 注入面 | `handles`（件要哪个能力面句柄 ← 描述符哪个键）与 `ops`（参数槽：名 / 类型 / 来源键 / 默认 / 非法收敛）；**来源必须分"现状"与"目标"两栏**，目标一律用 `→` 起头 | 每件至少一行 handles 或一行"不需句柄"；策略字面量必须在此出现或标 retired；**描述符里今天不存在的键（如 `[slots].present`）不得写成现状来源**——那是批J 之后的事，写串了施工就会去删既有段 |
| §4 主循环与时序预算 | 真实节拍常量（poll / tick / 上报周期）+ 每路输出的名义周期与**最坏延迟路径**+ 与心跳/看门狗的关系 + 饿死可见性 | 数字必须来自代码常量或 config；无实测的写"名义"，实测值进 §11 |
| §5 主题面契约 | 每主题：kind、seq 规则、触发条件（变化即发 / 周期 / 边沿）、载荷必填字段、失败映射 | 与 `contracts/topics.toml` 逐条对表；申报与实现不一致要在此明示 |
| §6 降级矩阵 | 行 = 格；列 = 缺格 / 句柄缺 / 句柄值错 / 后端未实装 / 参数非法。每格填**行为** | 空格视为未完成；"静默回落 sim"是缺陷不是行为 |
| §7 安全核接入 | 安全动作在哪一路、由哪个函数执行、能否被策略绕过（要写"不能，因为…"） | 无安全核的单元也要写明"无，因为…" |
| §8 两腿对拍用例设计 | 每**件**一行：合成输入序列、期望值来源（schema / golden / 裁定语义）、边界集、当前是否有测试 | 一条用例都不设计的册 = 该件还不能进门禁（ADR-0019 修订 2 ①） |
| §9 不变量与红线断言 | 可断言清单（每条写成"断言：…"），含对外面零改动项 | 写不成断言的不许列在此节 |
| §10 改造工单 | 批I/J/K 归属、动哪个文件、签名怎么变、回归面是什么、DoD 勾哪条、前置 C 项 | 无归属的缺陷要么并到工单要么进 §11 |
| §11 待证与敞口 | 只准出现这一节的推测与未测项，逐条带触发条件 | — |

## 三条通用约定（所有模块共用，各册不再重复论证）

1. **失败语义两分**：业务性失败折 `error` 应答、不断链；传输性失败 `exit(1)` 交监督复位
   （六单元一致，`rr3-act` 的 led 写失败例外——LED 是妆面件，只 `eprintln` 不退，这条例外在 §1/§6 各册点名）。
2. **时基**：目标一律 `Rr3TimeBase`（architecture §12.2），今天 act/bus 心跳用 `SystemTime` 的都在 §10 列工单。
3. **状态所有权**：句柄所有权不出主循环（interact 用 mpsc 动作通道是范例）；件不得自持线程。
