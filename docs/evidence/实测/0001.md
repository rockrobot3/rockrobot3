# 产线首烧实录（批N20 件一）

- 装配全链 `bash tools/deploy/image-esp32.sh --release`：验证面五步 PASS（espflash 4.6.0、
  rust-src、ldproxy、esp-clang、IDF v5.2.2）→ 构建 release 6m57s → 装配面
  `App/part. size: 1,086,848/4,128,768 bytes, 26.32%` → 自校验四查 PASS
  （0x1000=e9 / 0x8000=aa50 / 0x10000=e9 / 整片 4194304 B）。
- 直烧：`espflash write-bin --address 0` merged 4MB 全量覆盖（含 nvs@0x9000 区，
  NVS 随片清空＝产线首烧语义），98 秒写入。
- boot 实证（monitor 30s）：板上分区表 `2 factory factory app 00 00 00010000 003f0000`
  （espflash 内置模板表）；boot 段表加载 `segment 4: paddr=00050020 size=bb834h map`；
  `App version: 01c15f2`。
- 三达逐条：`I2C 扫描应答 [3C] ✓`＋`boot 画面已出（4 行）`；`姿态到位 pan=60 tilt=98
  （LEDC 回读 pan=60° tilt=98°）`；`[mic] 16074Hz L rms=34371 peak=57599 | R rms=34266
  peak=57599` 连续流＋`RAM point=2-periph-ready free=250660B`。
- fail-honest 实证：`[periph] 配置腿未装配（NVS 无存档且 RR3_BOARD_WIFI_SSID 未注入）
  ——N-13 服务面缺席，板其余功能照常`（不冒领配置腿）。
- 环境记录：板＝ESP32 rev3.1 4MB（`/dev/cu.usbserial-1420`），espflash 4.6.0，工作树干净；
  施工波折＝release build 目录 CMake 缓存源目录不匹配（v5.2.1 残留 vs IDF v5.2.2），
  清缓存重 configure 后过（缓存残留非码面问题）。
