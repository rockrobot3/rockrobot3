# 升级＋恢复两实录（批N20 件二）

- 前置（带注入构建）：`RR3_BOARD_WIFI_SSID/PASS` env 注入 → flash-esp32.sh --release
  重烧（app 1,086,912 B＝注入凭据串进 .rodata 比无注入多 64 B，烧录 79s）；boot 实证
  `配置腿起（N-13，凭据源=编译期）`＋`sta ip: 192.168.0.167`。
- 写口实录：`POST /api/board/wifi`（WXYYBG/12345678）→ curl 1.99s recv failure（HTTP 000，
  批N16 裁定的物理事实真板复现：apply 的 STA 重配置杀 socket＝应答送达尽力而为）；
  6s 后 `GET /api/board/state` 200（板以新凭据重新可达）＝确认语义旁证化。
- 升级实录（NVS 保留三行定案）：横幅尾加 `n20-live` 标记 → 去掉编译期注入重构建 →
  flash-esp32.sh 重烧（app 1,086,848 B，只写涉及分区，NVS 不在擦除域）→ boot 三行：
  `n20-live` 在横幅（新固件上板）＋`凭据源=nvs`（本构建无编译期注入，凭据只可能来自
  NVS＝POST 写入成功的硬实证）＋`sta ip: 192.168.0.167`（自动重连在线）。
- 恢复实录（回得来半边）：`espflash erase-flash` 全片擦 3s（镜像与 NVS 凭据同灭）→
  flash-esp32.sh 重烧（编译期注入保持）→ boot：`n20-live`＋`凭据源=编译期`（NVS 空 →
  读链三级回退回落实证）＋`sta ip: 192.168.0.167`（重新在线）。
- 环境记录：板＝ESP32 rev3.1 4MB（`/dev/cu.usbserial-1420`），espflash 4.6.0；写口应答
  语义与批N16 裁定一致（TCP 会话死亡＝物理事实，非缺陷）。
