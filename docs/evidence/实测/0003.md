# DoA 左/中/右分侧 3×10 实测（批N39 件四）

- 板：ESP32 classic rev3.1 4MB（UART2 1.5M 三线接 Pi）；`rrd` 测试期间停止，测后恢复。
- 探针：[doa_probe.py](../../../tools/pi-periph-probe/doa_probe.py) `ACCEPT <L|C|R> 10 10`；
  OLED 逐轮提示、侧别可听提示在倒数开始时响（距采集 3s），`AUDIO ON` 后丢 0.5s 起流瞬态。
- 判据：先 `adj = frac - (-1.115)`，`|adj|≤0.7` 判中，否则 `adj<0` 判左、`adj>0` 判右；
  主峰置信 `c < 0.06` 记无效（不计入有效轮）。每侧 ≥8/10 通过。
- 中段 10 轮 frac 中位 = **-1.115**（ILD≈0，站位正中）；这是固定通道偏置，不是站位错。
- 左首轮（无偏置）6/10 正确、7/10 有效；左重测（带偏置）如下，正式样本取重测。
