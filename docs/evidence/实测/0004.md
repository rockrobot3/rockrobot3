# 批N41 OLED 无绑定自愈回退真板验证

- 板：ESP32 classic rev3.1 4MB，USB `/dev/cu.usbserial-1420`；Pi 三线 UART2 1.5M 已恢复。
- 固件：N41 件一/二（注入优先、缺席回编译期装配锚；写失败路径 force；运行面每拍自愈退役）。
- 冷启动 UART0 关键行：

```
[periph] chip=esp32 pins=classic
[periph] I2C boot 解卡 ✓（SDA 本已高或已释放）
[periph] I2C 扫描应答: [3C] —— OLED 0x3C 在列 ✓
[periph] OLED init ✓（100k 档第 1 次过）
[periph] OLED ✓ boot 画面已出（4 行）
```
