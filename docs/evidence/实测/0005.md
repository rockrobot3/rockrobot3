# Pi 侧 UART 环回自检（批N39 现场会话）

- 前置：`sudo systemctl stop rrd` 释放 `/dev/ttyAMA0`；板侧三线断开；短接线仅 Pi pin8↔pin10。
- 发送与回显（长度 / 回显长度 / 结果）：

| # | 模式 | 长度 | 结果 |
|---|---|---|---|
| 1 | `RR3-LOOPBACK-0123456789\r\n` | 25 | PASS |
| 2 | 全可打印 ASCII 0x20–0x7E | 95 | PASS |
| 3 | `00 ff 55 aa 10 20 7f 80` | 8 | PASS |
| 4 | `A`×64 | 64 | PASS |
| 5 | `0123456789`×10 | 100 | PASS |

- 结论：Pi 的 UART 物理层（TX/RX/波特率/无流控）正常；问题不在 Pi 侧串口。
- 恢复：拔短接线、恢复 Pi pin8→ESP32 GPIO19(RX)、Pi pin10→ESP32 GPIO18(TX)、GND↔GND；
  启动 rrd 后 `rr3-sense` 日志出现 `音频源就绪 backend=esp32`＋`板面流就绪（16000Hz/2ch/s16le）`。
