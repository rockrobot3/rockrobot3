- 仓库与装机两份 profile 哈希一致（无需重铺）：
  - `pi4b-host-esp32-classic.toml`：`10ea5e5d50bde21b9e08e1f2b91d955488a68456d85780023091744e0daac41f`
  - `pi4b-host-esp32s3.toml`：`664a9417f8a5c5c376ee9b833991f4b5e65248ee101e4716dea9a76ec55c0eaf`
- 订正前：`/etc/systemd/system/rrd.service.d/profile.conf`
  `--profile /usr/lib/rockrobot3/profiles/pi4b-host-esp32s3.toml`（与实板 classic 不符）。
- 订正后：同文件 `--profile /usr/lib/rockrobot3/profiles/pi4b-host-esp32-classic.toml`；
  原文件备份 `profile.conf.bak-n42`。
- 重启验证：`rr3-ctl status` → connect/brain/interact/sense/act 五模块 running，
  `denied_publish = 0`；`rr3-sense` 日志 `音频源就绪 backend=esp32`＋
  `板面流就绪（实测 rate=16000 ch=2 s16le）`。

  S3 单板用 `esp32s3-mini.toml`；RK3566 用现成 `default.toml`/`distro.toml`（chip=rk3566）；
  **Pi4 独立 host-only 档待立 `pi4b-host.toml`**（当前 `pi4b-host-esp32-classic` 是带板组合）。
