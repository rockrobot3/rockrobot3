# Pi 4B 板侧五端口后端 release 构建（批N43 N43-3）

- 构建机：Pi 4B（`uname -m = aarch64`，主机名 <board-host>），`rustc 1.85.1` / `cargo 1.85.1`。
- 源码同步位置：`~/pi-periph-w4`——只同步 N43-2 的路径依赖闭包
  （`base/runtime` 全 workspace + `tools/periph-mech` + `tools/esp32-periph-base/atoms`
  的 face/servo 机制件 + `axis_gen.rs`/`topics_gen.rs` + `tools/pi-periph-base`），
  不改动板上的装机树（`~/robot`）。
- 构建命令与结果：

  ```text
  $ cd ~/pi-periph-w4/tools/pi-periph-base
  $ cargo build --release --locked
      Finished `release` profile [optimized] target(s) in 59.53s
  ```

  说明：`rr-ipc` 在 release 构建下报 4 条 `dead_code` 警告（golden 向量的
  `const fn`/常量仅测试面消费，属既有告警，不是本 crate 缺陷）。

- 产物：

  ```text

  dynamically linked, interpreter /lib/ld-linux-aarch64.so.1,
  BuildID[sha1]=a3ab8d4f4b497d4a1d57f0602a3fb47344043779,
  for GNU/Linux 3.7.0, not stripped
  $ ls -lh target/release/pi-periph-base
  -rwxrwxr-x 1 pi pi 810K Nov  2 22:34 ...
  ```

- 依赖/符号检查（三项均 0 命中）：

  ```text

  0 命中
  $ cargo tree --locked | grep -i esp
  0 命中
  ```
