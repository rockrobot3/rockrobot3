# N44 Pi4 独立 host-only 实机验收

- 板：Pi 4B（aarch64，hostname `spharx`，`192.168.0.194`），Raspberry Pi OS；
  装机 rrd 0.0.1（2026-10-31 构建），模块目录 `/usr/lib/rockrobot3/modules`。
- 装配：`profiles/pi4b-host.toml`＋`hardware/pi4b-host/wiring.toml` 铺到
  `/usr/lib/rockrobot3/{profiles,hardware/pi4b-host}/`，profile sha256
  `56984f3b36bdf7fa0434e5399b551f1787a2cb03ac3c136bad5098939ab2998d`。
- 起法：`sudo env RR3_DATA_DIR=/var/lib/rockrobot3 RR3_HAL_BACKEND=linux rrd
  --socket /var/run/rock3-ipc.sock --contracts /usr/lib/rockrobot3/contracts
  --profile /usr/lib/rockrobot3/profiles/pi4b-host.toml`（cloud.env 同 systemd
  drop-in 源入环境）。

## 1 启动与模块

```text
rrd: 装配单已加载: /usr/lib/rockrobot3/profiles/pi4b-host.toml
rrd: spawn rr3-connect pid=1229 ...
rrd: spawn rr3-interact pid=1230 ...
rrd: spawn rr3-brain pid=1231 ...
rrd: rr3-interact → running
rrd: rr3-connect → running
rrd: rr3-brain → running
```

`rr3-ctl status`：

```text
NAME          TASK  PHASE
rr3-connect   2     running
rr3-interact  3     running
rr3-brain     4     running
denied_publish = 0
```

`rr3-ctl health` 三模块心跳均在窗内（HB 2000/1000/2000ms，SINCE_BEAT≈0.9s）。

## 2 本机末梢

- 显示面：`[rr3-interact] 显示面就绪: backend=linux 8x8`；`/dev/spidev0.0` 在位
  （MAX7219，SPI0 CE0）。
- 播放面：`[rr3-interact] 播放面就绪: backend=linux rate=16000 ch=1`；
  `aplay -l` 见 `card 3: Device [USB Audio Device]`。采集面只有
  `card 2: sndrpigooglevoi`（voiceHAT），无 USB 采集，故本档不启用
  `audio.capture/vad`，与 `pi4b-host.toml` 的八格三模块一致。
- 面板：`面板就绪: http://127.0.0.1:8080（28端点）`。

## 3 链路后端

`RR3_HAL_BACKEND=linux` 时：

```text
[rr3-connect] 链路面就绪: linux up=true ssid=Some(WXYYBG) rssi=Some(-65)
[rr3-connect] 配网面就绪: linux 无在册凭据（出厂 ap）
[rr3-connect] 蓝牙面: phase=off（骨架，真后端板上后置）
```

不设 `RR3_HAL_BACKEND` 时 `rr3-connect` 落 `sim`（`ssid=rock-sim`）；这是
部署环境变量选择，不是 profile 数据缺陷。真链路起法须带 `RR3_HAL_BACKEND=linux`。

## 4 面板动作（MAX7219／USB 声卡）

```text
POST /api/face {"expression":"happy"}
{"ok":true,"result":{"expression":"happy","previous":"idle"}}

POST /api/beep
{"ok":true,"result":{"played_ms":200}}
```

两条均走 `rr3-interact` 进程内显示/播放路径，证明 MAX7219 表情面与 USB 声卡
播放面已接通。MAX7219 实际显示与扬声器出声待现场目视/听确认。

## 5 结论与余项

- N44 host-only 装配档在 Pi 实机可装载、三模块 running、真 WiFi 链路与
  显示/播放面就绪；`/api/face`、`/api/beep` 成功。
- 余项：MAX7219/扬声器物理确认；systemd drop-in 仍指向
  `pi4b-host-esp32-classic.toml`，是否把装机默认切到 `pi4b-host.toml` 待用户裁定
  （本验收为临时手动起，不改变装机默认）。
- `RR3_HAL_BACKEND=linux` 须随装机 drop-in 显式落位，否则 WiFi 落 sim。
