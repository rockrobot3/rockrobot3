## 2 旧固件：复位环与堆账

同一旧固件 60s 内出现 **12 次 boot / 11 次 `rst:0xc (SW_CPU_RESET)`**。RAM point：

| 点位 | 读数 | 判读 |
|---|---|---|
| `1-boot` | **273,072B** | 内部分配可用基线 |
| `2-periph-ready` | **249,012B** | UART2/I2C/OLED/LEDC 就绪后 |
| `3-mic-smoke` | **62,844～62,860B** | I2S0 双麦与音频上行起后 |
| `4-spk-play` | **15,608～32,920B**（主体 **22,152B**） | 播放面起后；两次 `[spk] 起播放线程失败: OutOfMemory` |
| 配置腿 | `esp_err=45064`（`0xB008`） | `ESP_ERR_HTTPD_ALLOC_MEM`：httpd 动态分配失败（栈 `HTTPD_STACK_SIZE=16,384B`）；9/12 次 boot 可见 |

复位环根因：`net` 心跳线程在 [`start_httpd`](../../../tools/esp32-periph-base/src/httpd/serve/start.rs)
里位于 `httpd_register` **之后**；httpd 在 16,384B 栈 + 会话面分配时 OOM，函数提前返回，
`net_watch_spawn` 永不执行；监督壳把 `net` 判死并整机复位。

```text
[periph] 配置腿启动失败 esp_err=45064（缺席照常；负值＝IDF 错误码）
[autonomy] 心跳超时 task=net（已标 dead；连续 2 拍不恢复即整机复位）
rst:0xc (SW_CPU_RESET),boot:0x17 (SPI_FAST_FLASH_BOOT)
```

## 3 修复版：复位环消失，内存结论不变

源码修复 `60381a0e`：`wifi_bringup` 成功后立即起 `net_watch_spawn`，再起 httpd。
CI `platforms #459` 产出 `esp32-classic-solo-firmware`（commit `2ecd1bea`），
`espflash flash` 写入后 60s 复测：**单次 boot、0 次 `rst:0xc`**，复位环消失。

`[mem]` 阶段读数：

| 阶段 | free | int_free | int_min | 判读 |
|---|---|---|---|---|
| `1-boot` | 268,560B | 295,384B | 295,384B | |
| `2-periph-ready` | 244,500B | 271,324B | 271,324B | |
| `mic-voice off` | 77,568B | 104,416B | 104,360B | 无 PSRAM，本地 VAD/分段停用 |
| `playout start` | **34,336B** | **61,160B** | 60,996B | 播放面起后 |
| `httpd start-fail` | 6,800B | 33,624B | 30,804B | `0xB008` 分配失败（栈 16,384B） |
| `status` | 41,396B | — | — | `min_free=4,012B` |

判读：

- 修复版播放面后 `free=34,336B`、`int_free=61,160B`；即便按较宽的 `int_free` 算，
  也只有 520KB SRAM 的 **11.8%**，低于 W7 的 20% 门；按 `free` 算仅 **6.6%**。
- `httpd` 仍以 `esp_err=45064`（`ESP_ERR_HTTPD_ALLOC_MEM`）失败；无 HTTP 配网面。
- SNTP 30s 未同步（当前无可用 WiFi 凭据），云请求前置不成立。
- 因此**全链 30min soak 不可执行**：VAD 停用、httpd 失败、云前置未成立；60s 复测
  只证明复位环修复，不替代全链 soak。

## 4 结论与余量

- **成立**：classic 真板可起 WiFi/I2S0 双麦/I2S1 播放/OLED/LEDC；双麦 L/R RMS
  约 34k、`L==R 0%`；`60s` 修复版零复位。
- **No-Go（当前实现）**：播放面后 `free=34,336B` / `int_free=61,160B`，httpd
  16,384B 栈 + 会话面分配仍失败；ASR 8s 段 512KB、TTS 回包 512KB、播放队列最多约
  1MB（见计划册 §20.2）均无法落内部 SRAM。该结论指**当前实现**，不是 classic 硬件终态。
- **未验证**：全链 30min soak 与云三跳未执行（httpd/VAD/凭据前置未成立）。
- **存储/流式候选**：本轮未测；需按计划册 §20.2 的三处改造（ASR 存储分块上行、
  TTS 边收边播、全链档不启 httpd）后再判，不把“候选”写成 Go。
