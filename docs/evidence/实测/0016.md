# Pi 4B W5-3 前置：YD2076 采集与 DoA 初测（2026-11-22）

## 1 现场与部署

| 项 | 值 |
|---|---|
| 板 | Pi 4B，`spharx` / 192.168.0.194，aarch64，Debian 13 |
| 部署 | `rockrobot3 0.0.11`；rrd active；profile `pi4b-solo`；五模块 running；`denied_publish=0` |
| 回放 | USB C-Media `0d8c:0012`（card 3），仅 playback |
| 采集（旧） | 板载 voiceHAT（card 2），2ch 实测全零（RMS 0.0 / peak 0） |
| 采集（新） | USB YD2076（card 4），2ch S16_LE 原生 48k，`plughw` 转 16k |
| 分流 | `/etc/asound.conf` 的 `pcm.rr3` asym：capture=YD2076、playback=Device |
| 配置 | `config-pi4b.toml`：channels=2、rms_start=120、window_rms_min=120、silence_tail=700、mic_baseline_mm=70（**临时标定值**） |

**注意**：`/etc/asound.conf`、`/etc/systemd/system/rrd.service.d/pi4b-solo.conf`、
`/usr/lib/rockrobot3/modules/rr3-sense/config-pi4b.toml` 都是本次现场改的
板上手工件；仓内尚无对应部署真值。原 asound 备份在
`/etc/asound.conf.bak-20261122`。

## 2 双麦采集

`arecord -D plughw:CARD=YD2076 -f S16_LE -r 16000 -c 2`：

- 底噪：L RMS 19.5 / R 16.4，peak 40–49（安静房间）。
- 语音段：L 300–1600、peak 30,445；R 185–660、peak 15,834。
- 通道独立、可分辨左右电平；原生 48k 经 plughw 转 16k 无误。

## 3 DoA 3×10（MAX7219 charL/charC/charR 提示）

观察器 `rr3-obs`（订阅 `rr3-sense/audio/vad_start`）原始记录：

| 站位 | onset 数 | DoA 结果 |
|---|---|---|
| 左（charL） | 7 | 全部 `right` / 50° |
| 中（charC） | 10 | 全部 `center`；deg −22、−3…+2（10/10） |
| 右（charR） | 8 | `right` 35–43°（5 次）+ `center` 14°（3 次） |

**判读**：中位稳定；左、右两侧都落到 `right`，左右不可分。不是阈值/唤醒门
问题（onset 与 rms_peak 均正常），而是阵列轴向、真立体声或通道顺序的
**几何前置**未成立。

**轴向旋转后复测（同日）**：把阵列轴线转向左右后，左侧站位 10 次 onset
仍为 **3 次 `left`/−50° + 7 次 `right`/33–80°**（角度分散），左右仍不可分。
说明该 YD2076 的两通道不是稳定的左右麦对（或阵列内部几何/通道增益不受控），
不是站位标定能解决的问题；W5-3 需换一个确认双通道独立的 UAC 阵列，或先做
阵列硬件核对。

**再次复测（原朝向，同日）**：左侧 10 次 `right`/50° + 1 次 `left`/−55°；
右侧 4 次 `left`/−50…−67° + 7 次 `right`/36–80°。两侧仍有大量同向混判，
进一步确认 YD2076 不能稳定分离左右。下一步需：

1. 确认 YD2076 的麦克风对轴向（左右应沿该轴，而非前后）；
2. 在右侧复录并比较 L/R RMS：若 R>L，则在 `/etc/asound.conf` 换通道；
   若 L 恒大于 R，则该阵列不是有效的左右双麦（可能单麦复制或固定增益差）。

## 4 观察器协议注记

恢复的退役 Python `bus.py` 与当前 rr-ipc 头有漂移：当前头在偏移 44 新增
CRC32（保留区 48..128），旧客户端把 CRC 当保留污染拒帧。临时件已改
`OFF_CRC32=44 / OFF_RESERVED=48 / LEN_RESERVED=80` 后可注册并收事件；
该 Python 客户端只作现场观察，不进产品码。

## 5 结论与余量

- **成立**：YD2076 双通道采集、VAD 触发（阈 120）、中位 DoA 10/10。
- **未成立**：左/右判向（两侧同判 right；轴向旋转后左侧仍 3 left + 7 right 混判）；
  YD2076 判定不能稳定承载左右 DoA，需换确认双通道独立的阵列。DoA→pan、云三轮、
  30 min soak 未做。
- **部署漂移**：asound/drop-in/sense 配置为板上手工件，待阵列几何定案后收编
  进仓（含 pack/安装面），不得长期留在板外。
- **旧硬件**：voiceHAT 双通道全零（peak=0）；C-Media 仅回放——二者都不能承担
  W5-3 的双麦前置。
