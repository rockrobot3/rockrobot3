# Pi 4B W5-3 前置：YD2076 互相关、DoA 3×10 与舵机链路（2026-11-22）

| 项 | 值 |
|---|---|
| 板 | Pi 4B，`spharx` / 192.168.0.194，aarch64，Debian 13 |
| 部署 | `rockrobot3 0.0.11`；rrd active；profile `pi4b-solo`；五模块 running；`denied_publish=0` |
| 回放 | USB C-Media `0d8c:0012`（card 3），仅 playback |

| 采集（新） | USB YD2076（card 4），2ch S16_LE 原生 48k，`plughw` 转 16k |

| 配置 | `config-pi4b.toml`：channels=2、rms_start=120、window_rms_min=120、silence_tail=700、mic_baseline_mm=**100**（现场标定） |

**注意**：`/etc/asound.conf`、`/etc/systemd/system/rrd.service.d/pi4b-solo.conf`、
`/usr/lib/rockrobot3/modules/rr3-sense/config-pi4b.toml` 都是本次现场改的
板上手工件；仓内尚无对应部署真值。原 asound 备份在
`/etc/asound.conf.bak-20261122`，换通道前备份在 `/etc/asound.conf.bak2-20261122`。

## 2 双麦独立性（互相关，决定性）

对 `/tmp/yd48.wav`（`hw:4,0` 原生 48k 2ch，后 3 秒人声）做 2 秒窗互相关：

| 指标 | 值 |
|---|---|
| 语音段 RMS | L 1157.1 / R 307.8 |
| 最佳互相关 | **0.8761** |
| 最佳时延 | **+13 样本 @48k = 0.271 ms** |
| 零时延相关 | 0.2047 |
| 反演路径差 | 0.271 ms × 343 m/s ≈ **93 mm** |

判读：两路是**独立间隔麦**（非复制、非降噪混音），左右轴存在真实时延。
此前 `mic_baseline_mm=70` 在 16k 下 `lag_max=round(16000×70/343000)=3`，
真实时延 4.34 样本落在搜索窗外，TDOA 峰被截断 → 左右混判。**不是阵列坏**。

## 3 DoA 3×10（最终配置，MAX7219 提示）

最终配置：`mic_baseline_mm=100`（16k lag_max=5，覆盖 4.34）+ `/etc/asound.conf`
采集通道交换（修正通道顺序）。观察器 `rr3-obs` 订阅 `vad_start` 原始落档：

| 站位 | onset 数 | DoA 结果 |
|---|---|---|
| 左（charL） | 10 | 10/10 `left`；deg −36…−40（3 次 −65） |
| 中（charC） | 10 | 10/10 `center`；deg 1–3（3 次 −15） |
| 右（charR） | 12 | 12/12 `right`；deg 59/65/90（10 次 90 饱和） |

**对照（修正前）**：baseline=70 时左侧 7 次全 `right`/50、中位 10/10 `center`、
右侧 `right` 35–43 + `center` 14，左右不可分——正是 TDOA 窗截断的形态。

## 4 舵机与 DoA→pan

- **PWM 直驱**：停 rrd 后手动 `period=20 ms`、`duty=2.0 ms`，舵机明显转动
  → 信号/UBEC/共地/机械链路通。
- **act 直调**：总线调 `rr3-act/servo/command {"axis":"pan","angle_deg":110}`
  回 `{"angle_deg":110,"move_ms":800}`，PWM 落 **1,722,222 ns**。
- **根因**：`rr3-sense` 反射环向 `rr3-act/servo/command` 发
  `{"pan": target}`，而 act 的 `rr3_servo_parse_args` 只认 `angle_deg`，
  以“缺 angle_deg”拒收；ESP32 桥走板侧命令旁路不经过这条总线，故只有
  Pi 宿主档静默失效。已改 `{"axis":"pan","angle_deg":target}`（`4a6b0e58`），
  Pi 侧待 CI 产物/重装后复验。

## 5 观察器协议注记

恢复的退役 Python `bus.py` 与当前 rr-ipc 头有漂移：当前头在偏移 44 新增
CRC32（保留区 48..128），旧客户端把 CRC 当保留污染拒帧。临时件已改
`OFF_CRC32=44 / OFF_RESERVED=48 / LEN_RESERVED=80` 后可注册并收事件；
该 Python 客户端只作现场观察，不进产品码。

## 6 结论与余量

- **成立**：YD2076 双通道独立；VAD 阈 120；**DoA 3×10 通过**（左/右/中各 ≥10）；
  舵机 PWM 与 act 参数面成立。
- **已修待部署**：sense→act 反射参数错配（`4a6b0e58`）；部署后需复验
  DoA→pan（说话侧转头）。
- **未做**：云 ASR→LLM→TTS 三轮（现场听到回复，但未按三轮计数落档）、
  30 min soak。
- **部署漂移**：asound/drop-in/sense 配置为板上手工件，待收编进仓（含
  pack/安装面）；不得长期留在板外。
