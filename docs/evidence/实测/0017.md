# Pi 4B W5-3：显示面 SSD1306 OLED 换装（2026-11-22）

## 1 硬件核实（先于任何改动）

| 项 | 结果 |
|---|---|
| I2C 控制器 | `/dev/i2c-1` 在位（GPIO2/3，`dtparam=i2c_arm=on`） |
| 从地址扫描 | 0x3C 写 2 字节 **ACK**；0x3D / 0x3E / 0x3F 均 `EIO`（无应答） |
| 结论 | SSD1306 128x64 单色屏 @ i2c-1 0x3C（与 `contracts/devices.toml` 的 SSD1306 `addrs` 域一致） |
| SPI | `/dev/spidev0.0` 仍在位（换装不拆旧路，MAX7219 档保留） |
| 摄像头 | `rpicam-still` 报 `no cameras available`——像素观感无法拍照取证，不冒充 |

## 2 契约与结构改动（机制/策略分离）

| 层 | 改动 |
|---|---|
| `contracts/roles.toml` | 新增 `ui.face.i2c`（slot=ui.face、iface=Rr3Display、requires=controller+addr+device、derives=i2c_bus+oled_addr）；新增 `group` 字段（缺省=角色名），`ui.face.spi`/`ui.face.i2c` 同组 `ui.face.phys` |
| rr-registry | `RR3_ASSEMBLE_DESC_KEYS` 增 `oled_addr`（与 rr-hal 描述符键集两处同批）；`Rr3RoleEntry.group` + `rr3_role_group` |
| rr-hal `descriptor.rs` | `Rr3HalBindings.oled_addr: Option<u8>`（7-bit 地址域，与 `ina219_addr` 共用 `rr3_i2c_addr_parse`） |
| rr-hal `backend/acts.rs` | 显示取档：`(i2c_bus, oled_addr)` 齐备 → OLED；否则 `spi_device` → MAX7219；两路并存当场点名 |
| rr-hal `linux_oled.rs`（新） | SSD1306 页式显存 1024B、8x8 帧 8 倍放大居中（X0=32）、16B 分块写、init 25 字节序列；纯函数单测 6 条 |
| rrd | `RR3_PIN_DERIVED_KEYS` 8→9（`oled_addr` 进门 n）；派生规则表 8→9；校验②改按绑定组判 |
| `profiles/pi4b-solo.toml` | 显示 `[[pin]]` 由 `ui.face.spi`(spidev0/ch0) 换为 `ui.face.i2c`(i2c1 / 0x3c / SSD1306) |

## 3 真机首启暴露的两个根因

### 3.1 I2C 设备名缺连字符（`bf23dba9`）

首启实测：

```
rr-hal: 显示面选 OLED（i2c1@0x3c，SSD1306 128x64）
rr3-interact 退出: 显示面探活失败(linux): oled 打开 "/dev/i2c1" 失败: No such file or directory
```

i2c-dev 的 UAPI 设备名是 `/dev/i2c-<bus>`（`i2c-dev.h` 的 `i2c-%d`），两处后端
（`linux_power.rs`、`linux_oled.rs`）都拼成了 `/dev/i2c1`。INA219 档此前无真件，
缺陷一直潜伏；OLED 真件首启即炸出。**同源同修**，两处均补连字符并以纯函数单测
钉死命名形状（`/dev/i2c-1`）。

### 3.2 校验② 按角色逐条判（`a32b593c`）

同格两角色（SPI 点阵 / I2C OLED）二选一的形态，在"逐角色判每条必须有 [[pin]]"
下必然互斥——装配单只能登记一条，另一条永远记缺。修法不是给 OLED 造例外，而是
把"同一物理位置的可替代实现"这一事实建模进契约：`roles.toml` 的 `group` 键
（缺省=角色名本身，既有角色零语义变化），校验② 按组判"组内至少一条绑定"、
全 logic 组跳过。缺组点名以组名第二列，既有可观测输出逐字不变。

## 6 结论与余量

- **成立**：OLED 硬件在位（0x3C ACK）、契约/驱动/装配三层落地、真机选档与出帧
  全链通过、五模块 running、表情点名三连 ok。
- **根修**：I2C 设备名连字符（两后端同源）、校验② 绑定组语义（契约建模而非例外）。
- **余量**：① 本机无摄像头，像素级观感（放大居中/对比度）未拍照取证，需人眼确认；
  ② 板端 `cargo test -p rr-hal`（含新 OLED 单测）未在板上跑，归下游批；
  ③ MAX7219 档仍在位保留，双显示并存属装配错误（选择面点名取 OLED）。
