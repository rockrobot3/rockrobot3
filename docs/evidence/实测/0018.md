## 3 SNTP 重试窗（余量①，决定性）

| 时刻（复位后） | sntp | ticks |
|---|---|---|
| ~35s | `unknown` | 155 |
| ~39s | `synced` | 183 |

WiFi 关联晚于旧实现的 30s 首窗：旧固件在此点已置 FAILED 并停止观察（0015
余量 4 的现场形态），v0.0.18 在 30s 首报后继续后台重试，约 39s 对时成功。
这是"重试窗而不是一次性"的直接行为证据。

## 4 真实语音轮（余量②/③）

用 `say -v Ting-Ting` 合成「你好洛克，请介绍一下你自己」→ `afconvert` 16kHz
mono WAV（123,506B，3.7s）→ `POST /api/board/dialog`（`X-RR3-Token` 开发令牌）。
应答 `{"ok":true}`（异步入队），随后轮询 state：

| 时刻 | tts_gate | tts_played | tts_fail |
|---|---|---|---|
| +5s | false | 0 | 0 |
| +15s | true | 0 | 0 |
| +20s | false | **1** | **0** |

即 ASR→LLM→TTS→播放全链完成：内部堆 24KB 准入通过、TLS 未出现
`create_ssl_handle` 失败、TTS 播放计数 +1。本轮链路良好未触发 ASR 重试分支
（码面 8s×3 + 500/1500ms 与 `HTTP -1` 可重试已由单测/CI 覆盖，弱网真板压测
留待有可复现弱网条件时补）。

## 5 观测面与已知缺陷

- **应用日志不在 CH340 UART0**：ROM 日志在 115200 可读，进入 app 后
  115200/921600/1.5M 三档均不可读（噪声）；HTTP 遥测正常。有效控制台疑为
  USB-Serial/JTAG，接原生 USB 口才能取 `[periph]/[sntp]/[mem]/[dialog]` 行。
  这本身是"信息打印可达性"的结构缺陷，登记待下轮（控制台显式钉 UART0 或
  双通道）。
- **HTTP reboot 后未回 STA**：`POST /api/board/reboot` 后板广播 `RR3-BOARD`
  SoftAP，未自动回连家庭 WiFi；`espflash reset` 硬复位后立即回连并取得
  192.168.0.172。属既有配网/重连路径缺陷（与本轮 S3 三项无交集），登记待根修。
- 弱网重试分支未真板压测；本轮只证明"正常网 + 堆准入 + 真实语音全链"。
