```
drwxr-x--- 2 root rockrobot3 160 /run/rock3-ipc.sock.log
```

### 3.2 logs --unit（无 sudo）

```
$ rr3-ctl logs --unit rr3-sense | tail -1
面选择: hal=linux audio=linux rate=16000 ch=2 frame_ms=20 doa_window_ms=1000 reflex=on

$ rr3-ctl logs --unit rr3-brain | tail -1
唤醒应答预合成就绪: 410ms pcm_bytes=104878

$ rr3-ctl logs --unit ../etc/passwd
rr3-ctl logs: 模块名非法 ../etc/passwd（只认 rr3-<小写字母>）
```
