# ESP32-S3 新功放接线与全链体验（2026-11-23）

## 1 接线（真板验证正确）

| 功放模块 | S3 N16R8 |
|---|---|
| VCC | 5V |
| GND | GND（共地） |
| LRCLK / WS | GPIO17 |
| BCLK / SCK | GPIO16 |
| DIN / SD | GPIO18 |
| 喇叭 | 模块 JST 输出 |

固件侧对账：`[spk] 播放面起：I2S1 TX 16000Hz 16bit stereo ring=16384B`。

## 2 对话体验（串口实录）

```
[mic] DoA bin=center deg=-8
[mic] VAD onset（预滚 600ms）doa=center/none path=mem
[mic] 语音段入队 2080ms（offset）
[mem] stage=dialog phase=asr-ok
[spk] 播放完成 pcm=90798B 应播=2837ms 实耗=2774ms 误差=2%
[dialog] 唤醒应答 asr='你好，洛师。' ack='我在呢，有什么可以帮您？' tts_ms=2837 pcm=90798B
[dialog] 唤醒命中，命令='今天上海的天气怎么样'
[spk] 播放完成 pcm=396718B 应播=12397ms 实耗=12306ms 误差=0%
[dialog] 轮完成 22398ms asr='今天上海的天气怎么样'
  reply='让我帮你查下上海的天气吧~(叮~) 今天上海多云转晴,18-24°C,建议带件薄外套哦!'
```

两轮均完成，`tts_fail=0`。

## 3 缺陷：对话后功放长响

- 现象：对话结束后喇叭持续响（DMA 残留被反复放大）。
- 根因：`play_run` 在 `Action::Idle { running: false }` 时直接睡 `PLAY_IDLE_MS`
  （1000ms），I2S1 TX 保持 enable，DMA 无人喂数 → 空转放大残留。
- 修复（`e03ac2c2` + `60b7e84a`）：空闲时阻塞写全零帧（`PLAY_SILENCE`，
  按 DMA 消费自然节流 ≈32ms/块）。既不断流也不空转；时钟保持，起播无 pop。
- `PLAY_IDLE_MS` 降为 audio-out 看门狗窗判据基准（playout 不再长睡）。

真板复验：

- 启动：`console=uart0@115200 secondary=none`、`chip=esp32s3`、
  `[spk] 播放面起`、`sta ip: 192.168.0.172`、`wifi-sup: STA 在线`全在册。
- 自动对话轮：`gate` t=6s 起 true、t=18s 转 false，`tts_played` 0→1，
  `tts_fail=0`。
- **静音确认**：播放完成后连续 24 秒 `gate=false`、无新播放；现场确认喇叭
  安静（此前旧固件同场景会持续响）。空闲喂零帧修复成立。

## 5 余量

- DoA 两次判 center（-17°/-8°）：站位偏角不足 30°，舵机未转；听声识位需
  再取偏侧（>45°）样本。
- 空闲喂静音为常开时钟方案，未做长时间静置功耗测量。
