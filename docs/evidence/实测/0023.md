## 5 运行窗观察与敞口

- 运行窗周期行正常：`[mic] 15992–16103Hz L rms=37952–42913 peak≈123135 | R rms=34335–35884`，`L==R 0%`，`build=0.0ms×0`；无 panic、无重启。
- 启动早期出现过一次 `[mic] dump 逐窗不变（疑似 SD 虚接/停摆） 00…`，随后周期行 RMS 非零；按启动瞬态记录，不据此判麦克风故障，现场如需定量需做一次已知声源复测。
- STA：NVS 有凭据（`凭据源=nvs`），`wifi-sup: 重连 attempt=1..3 esp_err=12295/0`，本场未连上；`/api/board/health` 如实返回 `{"shell":"off","sntp":"unknown"}`——classic 无 STA/sntp 属既有 No-Go 口径，不写成在线。
- 未执行：ESP32-S3 full（无 S3 板）；Pi 探针窗口 C（两板 UART 三线未接通，`ttyAMA0`/`ttyACM0` 均 0 字节）。

## 6 复现命令

```bash
# 制品校验
shasum -a 256 rr3-periph-base-esp32-safe-dev.elf rr3-bootloader-esp32-dev.bin
# 烧录（不构建）
bash tools/deploy/flash-artifact.sh <elf> --chip esp32 --bootloader <bin> --port <dev>
# 启动日志（RTS→EN 线序复位；或 console-log.py 运行窗）
python3 tools/deploy/console-log.py -s 20 -o /tmp/rr3-esp32-boot.log
```
