## 2 v0.0.22 失败与根修

- v0.0.22（tag `a99b1e87`）publish 两次均失败于同一 job 的同一 step：
  `build-riscv64` → “构建 riscv64 镜像（含两段冒烟）并推送（带 provenance/SBOM）”，
  两次耗时 2m24s / 2m11s；amd64、arm64、firmware 均 success，merge 因 riscv 失败跳过。
- 匿名 API 无法读 job 日志（403）；按脚本与宿主平台差异定位：发布腿在 **amd64 runner**
  上 `docker pull "$tag"` 拉取 **riscv64-only 索引**，未带 `--platform` 时 Docker 以宿主
  平台选清单，必然 “no matching manifest”；amd64/arm64 腿宿主匹配故不暴露。
- 修复（`dfd84ef4`）：统一 `pl="linux/riscv64"`；`buildx build`、`docker build`、
  `docker pull` 均显式 `--platform "$pl"`；两段 `image-smoke` 以
  `DOCKER_DEFAULT_PLATFORM="$pl"` 运行。另加 ERR trap（`d75d22d6`）点名失败行号与原命令。
- 验证：platforms `dfd84ef4` 三线 success（riscv-image 腿跑非推送路径）；
  v0.0.23 `build-riscv64` success，merge success。
