## 1 背景与目标

### 1.1 背景

验证面已齐：0.0.6（树莓派）收口 + 0.0.7 四层梯子全收官——契约 parity（批B）→
UART transport 板级 round-trip（批C④⑤）→ espidf-sentinel 哨兵进城（批D1，
roundtrip 峰值剩余堆 ≈ 启动堆 85%）→ rr3-bridge 桥 + 真板 e2e 断链自愈（批E）→
点验矩阵 esp32-mini 行七格收口（批G）。**跨厂家板子部署的底座地基已验证**：
宿主 ↔ ESP32 按在册主题收发、心跳看门狗、断链自愈全部真板实锤——按 R31 版本制，
这正是"验证功能的可成功运行"使命的兑现，功能落地归 0.0.5 新轮次。

用户在手硬件（2026-10-11 确认）：ESP32 经典款开发板全套、二自由度舵机（云台）、
0.96 寸 OLED 屏（SSD1306）、INMP441 麦克风 ×2、MAX7219 点阵模块。用户明确目标：
**先把语音对话、OLED 显示、舵机转向三项功能做出来**。

### 1.2 目标（一句话）

宿主（树莓派）经已验证的桥链路，对 ESP32 协处理器上的 OLED、云台舵机下发指令
并实时出效果；INMP441 双麦采集的音频经桥上行宿主，完成"说话 → ASR → brain
应答 → TTS 播放"的语音对话闭环。

### 1.3 本轮不做（明确范围外）

- **MAX7219 点阵表情链路**：用户三项功能不含点阵；SPI 表情出帧的既有硬约束
  （0.0.5 立项）存档不注销，归后续功能轮。批B 固件档预留 SPI 引脚不占用即可。
- **唤醒词（KWS）**：经典 ESP32 无 esp-sr、无 PSRAM，板上唤醒词不可行；初版
  语音对话用**触发式收音窗**（面板/按键触发 + 能量门限 VAD），唤醒词后置另裁。
- **brain 迁移细化**：语音对话挂现有 rr3-brain 对话模块（ADR-0014 M4 闭环），
  迁移仍按 ADR-0016 排期（0.0.8）走，不与本轮混排。

## 5 设计要点

- **波特率参数化**：transport 构造参数 + 桥 CLI 参数各加一档，默认值不变
  （115200）——ADR-0008 接缝纪律：只加参数不改 trait 面；非音频链路不受影响。
- **音频帧契约**：音频走独立主题（不与控制/心跳混流），payload 分片定长
  （分片大小随批D 设计要点钉死）；丢帧/背压语义进 envelope.schema.json
  coverage——音频允许丢、控制面零容忍，写进契约不靠约定。
- **板上固件形态**：espidf std + 复用 rr-core::runtime（哨兵同构），外设驱动
  按 embedded-hal 原语最小实现；线程栈 16KB 下限沿用；I2S DMA buffer 计入
  三点 RAM 复测（批D 判据沿用 20% 阈值）。
- **引脚预算（约束面）**：UART2 = GPIO16/17（已占用）；I2C（OLED）= GPIO21/22；
  I2S 候选 = GPIO25/26/27 区（随批D 钉死）；SPI（点阵预留）= VSPI 缺省组不占用
  不使能。与 0.0.7 实测接线零冲突。
  **2026-10-14 订正（此句已被实机推翻）**：UART2 实际落在 **GPIO18/19**——`board.rs` 的引脚真值表自述
  "GPIO16/17 一装 UART2 驱动即把 I2C0 打死，弃用"，即**上面这份预算的第一行就是错的**，而且新脚
  **19 与点阵 VSPI 预留同脚**（"点阵立项时需再迁，已在案"——这条互斥**今天仍未闭**）。
  I2S 走 25/26/27 一支与预测一致、未演化为损失。订正后的正确形态不是再写一段散文，而是把这三条
  互斥落成数据：`[pins].mux_group`（`uart2.default ↔ i2c0.oled`、`uart2.tx/rx ↔ display.panel.matrix`）
  + 装载期校验③"同脚不双占"与④"互斥组不共启"——见
  [增补轮六全案](0.0.5增补轮六——底座资源模型与能力面抽象补课全案.md) §4.2/§5 与
  [ADR-0021](../adr/ADR-0021-三独立形态与资源供给面-能力原子化补课.md) 裁定 3。
- **舵机供电**：UBEC 独立 5V 轨 + 单点共地铁律进批B 装配步（判据内含电压
  核验）；舵机信号线 3.3V 逻辑直驱 SG90 级兼容。**注**：这两条硬约束写在文档、违约发生在实机
  （板载 USB 5V 直供 + 堵转持续电流 = BOD 复位循环）——软件侧的对应物今天不存在，
  随 ADR-0021 裁定 2 立 `[[supplies.domain]]` 与件的 `demands` 申报才第一次可校验（power P-9/P-10）。
- **DoA 口径**：双麦 → 一维方位角（左右分辨、前后镜像模糊），初版够"云台
  转向声源"用；镜像模糊的处置（声学遮蔽/第三麦）不在本轮。
- **ASR/TTS adapter 缝**：trait 定在 brain 对话模块侧（ADR-0014），本地实现
  首发；云后端实现位留空不写半成品（ADR-0008 裁定 4 口径）；brain 迁移
  （ADR-0016）发生时 adapter 随迁不破。
- **0.0.7 排障实锤直接复用**：cu.* callout 节点 / stty 同 fd / 残留旧桥 ps
  清场 / DTR 复位时序（rrd socket 先就绪）——批D/批E runbook 引用不重写。

## 6 Definition of Done（增补轮五收口判据）

1. OLED：宿主指令 → 真板 OLED 显示指定内容，e2e round-trip 回读一致。
2. 舵机：宿主指令 → 云台两轴转到指定角度（≥5 点扫描），真板 e2e。
3. 语音：真板端到端"说话 → 应答出声"≥5 轮回归过；ASR/TTS 可换型（adapter
   缝真实存在——换实现不改对话模块）。
4. DoA：双麦方位角随声源左右移动单向变化（批D 判据兑现）。
