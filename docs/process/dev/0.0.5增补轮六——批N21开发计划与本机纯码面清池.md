### 件一：uart 排他账本 O_CLOEXEC 拆修

- 撤临时诊断代码（excl_enter 内 `RR3_UART_EXCL_DIAG` 块）。
- `imp` 两份平台常量各钉 `O_CLOEXEC`（macOS SDK fcntl.h ／ Linux uapi fcntl.h，数值互异
  注记留痕）＋`const _` 尺寸无关不适用（常量无 ABI 断言面）。
- `excl_enter` guard fd 与 `open_with_baud` 通信 fd 的 `c_open` oflag 加 `O_CLOEXEC`。
- 模块注记补根因实录段（spawn 继承 → description 副本钉锁 → O_CLOEXEC 排除；测试与生产
  两形状同理由）。
- 判据：单跑绿＋单进程多线程 workspace 压测多轮全绿＋双进程并发多轮全绿（批N19 注记的
  修复判据）；`cargo test -p rr-ipc` 全绿。
