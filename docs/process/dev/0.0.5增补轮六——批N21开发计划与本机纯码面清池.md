### 件一：uart 排他账本 spawn 瞬态拆修（O_CLOEXEC＋守门用例有界重试）

- 撤临时诊断代码（excl_enter/excl_exit/pty 分配/跨进程用例的 `RR3_UART_EXCL_DIAG` 块全撤）。

- 模块注记根因实录段按最终定案改写（spawn fd 表复制窗口＋O_CLOEXEC 边界两层）。
- 判据：单跑绿＋workspace 压测多轮全绿（实测 90/90：30 轮裸跑＋60 轮 --nocapture，瞬态
