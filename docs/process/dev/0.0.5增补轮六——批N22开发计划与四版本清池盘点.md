## §2 件表（依序施工，每件一提交）

### 件一：敞口 15 写面半边——面板配置面三写口端点挂接

- **三写口**：`armed=true` 置位／`severe_mv`／`current_ceil_ma`（conventions §6.1 :3170-3172
  点名的三个写动作）；写面挂接语义＝面板配置面获得对装配单域表
  `[[supplies.domain]]` 四键（`armed`/`evidence`/`severe_mv`/`current_ceil_ma`）的写口。
- **写权限边界**（ADR-0021 裁定 6 :235-237）：拒动类阈值（`severe_mv`、`armed`）的写必须带
  **二次确认与留痕**（运维面非安全旁路）——请求缺确认位即拒，写动作留审计痕迹。
- **fail-closed 四道核**（conventions §6.1 :3166-3168）：写面对出现的 evidence 引用走
  `rr-ipc::evidence` 四道核（形制/存在/frontmatter 六键/form 与目录一致），任一道不过即拒写；
  校验器唯一实现已住 rr-ipc（批N4 件一），写面是它的第二个消费面（装载期批N21 件二为第一个）。
- **落盘生效语义**：写口落盘 profiles 档，运行中不热重载——生效经 boot 重装载同链被核
  （批N21 件二注记原文："面板写面落盘的数据经 boot 重装载时同链被核"）；写口应答如实点名
  "下次 boot 生效"，不宣称即时生效。
- **端点形状**：照批N4 件九先例（`RR3_PANEL_ROUTES` 白名单四列表＋BusCall 透传或 rrd 侧
  RPC 选型，施工时按 rrd RPC 面侦察定形）；covers/applies 如实申报进 ⑩（读面可写即申报，
  防 ⑩ 越界红）。
- **判据**：三写口红绿单测（无确认拒／引用非法拒写／合法过写留痕）＋既有全量不破
  （check.sh 全量绿；门 d 分母/covers 变动同批对账基线）＋敞口 15 行结项。
