## 3 开发计划（主线：0.0.5 开发窗内批N2–N5 依序）

排序依据承全案 §9 既有裁定——**按资源约束的依赖方向，不按人员**：N2（能源）在 N3（执行件）之前
（执行件的电流上限、标定护栏、拒动语义全以域为参照）；N4（面板）最后（显示前三批形状）；N5 消费 N1–N4 形状。
每批沿用既有节奏：**每小步一提交一推送，三远端 `git ls-remote` 核对一致，`bash tools/ci/check.sh` 全绿才提交**。
