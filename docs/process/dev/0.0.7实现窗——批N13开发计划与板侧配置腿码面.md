## §2 件表

### 件一：板侧配置服务本体（`httpd.rs` 立件）

- **载体**：`esp_http_server`（IDF 内置组件，零新外部依赖——批N4 件二定案）；HTTP/1.1
  子集口径（GET + Content-Length + JSON）与 host 面板
  [server.rs](../../../modules/rr3-interact/src/panel/server.rs) 同形。
- **形状**（与 host `RR3_PANEL_ROUTES` 同构）：`RR3_BOARD_ROUTES` 白名单路由表
  （method/path/covers 列）＋路由纯函数 `rr3_board_route`＋`route_table_matches_dispatch`
  漂移单测（表↔分派零漂移钉死）。
- **端点集（首笔只读）**：
  - `GET /api/board/state`——板侧运行态观测快照 JSON（`PeriphState` 观测字段：
    rail_mv/rail_tier/move_fail_events/selfheal_skipped/binding_mismatch/audio_* 等，
    快照取自有界锁窗，不持锁出 JSON）；
  - `GET /api/board/bindings`——当前注入绑定十键真值 JSON（批N9 件五对账锚同源读数）。
  - 白名单外路由/方法一律 404/405 fail-closed（同 host 面板语义）。
- **任务/堆账**：`httpd_config_t.stack_size` 定值并入 task_stack 账面注释留痕
  （`task_stack_budget_bytes = 65536` 容 3×16K 余量充足；httpd 内部任务非
  `thread::spawn` 自建，账面口径在注释写明）；运行堆从预留 16384 出（批N4 件二
  已在 ⑩-b 留痕），不动 `heap_reserved_bytes`。
- **判据**：`tools/ci/esp32-periph-base-check.sh` 甲面构建 PASS（本机 esp 工具链
  真跑非 SKIP）＋路由/白名单/漂移单测＋decisions §4 变更行。

### 件二：板侧 covers 申报进 ⑩（门 d 对拍执法）

- **事实**：板侧端点读对象两族——观测计数（不在 ⑩ 分母五路）＋绑定十键（pin 路
  在分母，host `/api/wiring` 已 covers 全绿）⇒ 预期**门 d 分母/红账/基线零变动**。
- **落法**：[check.sh](../../../tools/ci/check.sh) ⑩ 步 covers 扫描源扩入板侧
  `RR3_BOARD_ROUTES` 区段（同一段扫描逻辑复用），对拍判据＝板侧 covers 集 ⊆
  分母五路并集（越界即红，硬红不入基线账——申报制语义保住：板侧端点不许读
  五路之外的可配置字段而不申报）。
- **判据**：check.sh 全量 PASS＋门 d 数字零变动核对（分母 82 / covers / 红账 0 /
  gate-d-baseline.txt 零改动）＋decisions §4 变更行。
