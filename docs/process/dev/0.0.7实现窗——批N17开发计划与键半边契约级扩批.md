## §1 范围定性

本批＝**N-10 ② 键半边契约级扩批**（批N14 件二缓批裁定的兑现；[bindings.rs :67](../../../base/runtime/rr-ipc/src/bindings.rs)
原文「扩键走契约级评审并两处同批」即本批依据）——`cred_store` 键进 `[hardware]`/绑定域，
**三处同批**（rr-ipc `RR3_BOARD_BINDING_KEYS` 十键封闭表＋rr-hal `Rr3HalBindings` 字段集＋
rr-registry `RR3_ASSEMBLE_DESC_KEYS` 白名单）＋contract.rs 机判同批＋桥上注入链自动带键＋
板侧读数面随键。

**键语义与取值域**（全案 §3.6 凭据行定形）：`cred_store = "nvs:rr3"`——**存储源标记，
非凭据值**（SSID/密码零回显契约不涉；「凭据在哪存」是声明面）。取值域裁决＝`nvs:` 前缀＋
非空 namespace（fail-closed：非 `nvs:` 前缀或空 namespace 点名拒收；裁决函数真值单点在
rr-ipc，rr-hal 描述符臂与板侧载荷臂同调）。**消费语义＝板侧读数面可见**（GET
`/api/board/bindings` 随键）——boot 读链不消费（批N14 架构事实：桥上注入晚于 WiFi 起栈，
唯一可能读者只剩注入后一致性校验薄读者，裁定不立）；无装配对账语义（非 GPIO，不进板侧
对账锚——对账只对 GPIO 十键）。

**B 块裁定（宿主面板凭据可见，N-10 ② 宿主半边）＝另批**：panel server.rs 凭据状态可见面
是独立观测面工作（涉门 d 分母扩），与本批键半边解耦——如实登记不混批。

**不排项（如实登记）**：

| 项 | 归宿 |
|---|---|
| 宿主面板凭据可见（N-10 ② 面板半边） | 另批（独立观测面工作，涉门 d 分母） |
| board 凭据源切换（`cred_store` 板侧 boot 读链消费） | 不排（批N14 架构事实：注入晚于起栈，薄读者不立） |
| 产线闭环码面（镜像装配/OTA/回滚） | 批N18 |
| L-32 shm 摘面／基-33 Windows 可编面 | 0.0.8 整理窗（批N19 前置核实） |
