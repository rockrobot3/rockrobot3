## §1 范围定性

本批＝**微型形态（ESP32）产线闭环四件的余量三件**（[status.md 敞口表](../../status.md) 第 13 行
原文「镜像装配/OTA/回滚三件仍敞」；烧录封装已随批N9 件二收）。施工依据＝
[全案 §17 批N5](0.0.5增补轮六——底座资源模型与能力面抽象补课全案.md)「升级与回滚」行＋
「烧录与装机」行 ESP32 半边；裁定来源＝
[ADR-0022 裁定 6.4](../adr/ADR-0022-代码事实复盘-机制核纯净度与申报面逃逸与安全语义身体.md)
（微型形态的产线与升级闭环复盘确认今天是空的，立为批N5）。

**侦查钉死的三块物理事实**（2026-10-23，本机实测，非转述）：

1. **分区表＝IDF 缺省三分区，factory 单槽**：`tools/esp32-periph-base/target/xtensa-esp32-espidf/debug/partition-table.bin`
   二进制手读（magic 0xAA50 逐项）：`nvs@0x9000/0x6000`（批N14/15 凭据源）＋
   `phy_init@0xf000/0x1000`＋`factory@0x10000/0x100000`（1MB 单 app 槽）——
   **无 ota_0/ota_1/otadata**＝件三语义的物理前提；
2. **镜像装配载体现成**：espflash 4.6.0 `save-image --chip esp32 --merge`（bootloader.bin＋
   partition-table.bin＋app 段自产物树合单文件，`--flash-size 4mb`）——与 `6d3a1ee`
   descriptor 先例同一产物面；
3. **构建产物三件同树**：ELF 与 `bootloader.bin`/`partition-table.bin` 同目录
   （`target/xtensa-esp32-espidf/<BUILD>/`），装配脚本不需二次定位逻辑。

**三件语义定型**（本批的裁定内容）：

- **件一 镜像装配＝码面**：`tools/deploy/image-esp32.sh`——验证面复用
  `flash-esp32.sh --check-only`（五步链真值单点不抄第二份：工具链门→构建→产物断言→
  descriptor 三查→干跑止步）＋装配面（save-image --merge）＋自校验面（merged 镜像
  布局三点断言：bootloader@0x1000 magic 0xE9／分区表@0x8000 magic 0xAA50／app@0x10000
  magic 0xE9＋镜像尺寸 < 4MB flash 预算）。判据＝脚本面本机干跑绿（批N9 件二
  `--check-only` 先例口径；**不进 check.sh 主门**——板侧构建走专用门
  `esp32-periph-base-check.sh`，主门数字零变动）。
- **件二 OTA 语义＝明文裁定＋表改判**：全案 §17 判据原文「ESP32 侧明确本形态的
  回滚语义是什么（'不可回滚'也是一句合格答案，但必须写进表）」与「表内'不能'一格
  必须带触发条件」。本形态升级语义定案＝**重烧即升级**（`flash-esp32.sh` 全镜像重烧＝
  产线可复现升级路径；NVS 凭据保留＝升级后免重配网——`espflash flash` 只写涉及分区，
  nvs@0x9000/0x6000 不在擦除域）。真增量 OTA（ota_0/ota_1 双槽＋下载链）**不做**，
  三理由在案（无双槽分区表——4MB flash 预算重裁；无下载载体——形态无 FS、配置腿
  HTTP 无 TLS、云分发面未立；`rr3.ctl.ota` 恒拒面维持 M6 评审归属）。落点＝
  [partition-layout.md](../../../base/ota/partition-layout.md) ESP32 语义段（明文结论
  唯一真值点）＋[可达终点表](0.0.5增补轮六——批N5首件——按形态分档可达终点表.md)
  §2/§3.3 升级格改判。
- **件三 回滚语义＝明文裁定＋表改判**：终态结论＝**不可回滚（无自动回滚链）**——
  factory 单槽无 A/B、bootloader rollback 未启用、烧坏即串口重烧（产线人工兜底）；
  "回得来"半边如实登记＝①重烧重试路径（USB 在手，`flash-esp32.sh`）②NVS 凭据保留
  （重烧不擦 NVS，配网成果不丢）。触发条件＝形态启用双槽分区表（ota_0/ota_1＋
  otadata）＋`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE` 走契约级评审。落点同件二
  （同段回滚半边＋可达终点表回滚格改判）。

**随批对表三格**（[可达终点表](0.0.5增补轮六——批N5首件——按形态分档可达终点表.md) §4
维护纪律 1「批件收官时对应格改判列入交付清单」）：烧录格（§3.3 :95，批N9 件二落脚本
