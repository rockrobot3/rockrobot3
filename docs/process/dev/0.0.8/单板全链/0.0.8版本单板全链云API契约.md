# 单板全链云 API 契约（2026-11-19）

- **状态**：生效（W0-2 收口件）。本页是 Pi 4B / ESP32-S3 / ESP32 classic 三形态
  共用的**云端接口唯一口径**；实现细节以代码为准，口径冲突时先改本页再改代码。
- **来源**：三家端点、请求体与重试策略逐项取自现有真云实现
  [`rr3-brain/src/cloud`](../../../../../modules/rr3-brain/src/cloud)；本页只做跨形态收口，不另造协议。
- **适用范围**：单板全链的 `云 ASR → 云 LLM → 云 TTS` 三跳；不含 OTA、面板与运维 API。

## 0 传输与鉴权

| 项 | 口径 |
|---|---|
| 协议 | HTTPS，JSON 或 `multipart/form-data` |
| 鉴权 | `Authorization: Bearer <key>`；key 为空时 local 免鉴权路径允许不带该头 |
| 基址 | OpenAI 兼容服务基址（`base_url`）；三家路径拼在基址后 |
| 时间 | 开机 SNTP 对时；时间未同步或证书校验失败时**拒发请求并显式点名** |
| 证书 | 根证书随固件/系统；不允许明文 HTTP 回退 |
| 连接 | Pi 侧共享连接池；MCU 侧由 `esp_http_client` 管理，单轮串行 |

## 1 ASR：`POST {base_url}/v1/audio/transcriptions`

请求：`multipart/form-data`，字段顺序固定：

| 字段 | 值 |
|---|---|
| `model` | ASR 模型行 |
| `language` | `zh`（中文；服务端忽略时无副作用） |
| `file` | WAV 文件，`filename="a.wav"`；16 kHz mono s16le |

- WAV 头由板端生成（44 字节 RIFF 头），PCM 不压缩。
- 送云前可做输入增益（现网 `×4`）；增益只作用于送 ASR 的副本，VAD/DoA/总线 PCM 不变。
- 单段音频上限按对话轮配置；超时由调用方判停，不把长静音整段上传。
- 应答：200 + JSON `{"text": "..."}`；缺 `text`/非 JSON 一律判失败。

## 2 LLM：`POST {base_url}/chat/completions`

请求：`application/json`，OpenAI 兼容：

```json
{
  "model": "<模型行>",
  "messages": [{"role": "user", "content": "..."}],
  "max_tokens": 150
}
```

- 系统提示词与人设由实现侧固定；历史轮次按 `role/content` 顺序放入 `messages`。
- 应答：200 + `choices[0].message.content`；取不出即判失败。
- `max_tokens` 是策略量，可配置；默认 150。

## 3 TTS：`POST {base_url}/v1/audio/speech`

请求：`application/json`：

```json
{
  "model": "<模型行>",
  "input": "<回复文本>",
  "voice": "<音色>",
  "response_format": "pcm",
  "sample_rate": 16000
}
```

- **只接受原始 PCM 流**（`response_format=pcm`）；WAV 仅在供应商返回 WAV 时按
  `data` 块抽取。
- **不解码 MP3/AAC**：供应商只给压缩格式时显式报错，换供应商或加代理，不引入解码器。
- 应答：200 + 原始 PCM 字节流（`read-until-close`）；空体判失败。
- 采样率以请求值为准；板端播放前核对设备支持率，不一致时重采样或改请求值。

## 4 超时、重试与错误分级

| 项 | 口径 |
|---|---|
| 单次超时 | 8 s（三跳同源；必须 < dialog 心跳窗 10 s——阻塞读期间无法续拍） |
| 尝试次数 | LLM / TTS 最多 2 次；ASR 最多 3 次（弱网韧性靠多一次尝试，不放宽单跳） |
| 重试间隔 | LLM / TTS 固定 500 ms；ASR 500 ms → 1500 ms |
| 可重试 | HTTP 429、5xx、传输层（连接拒绝/超时/读断，含 `HTTP -1` 负状态） |
| 不重试 | 鉴权 4xx、请求形状 4xx、坏应答、缺密钥、缺字段 |
| 失败文案 | `云端不可达 {url}: {原因}` / `{接口} HTTP {code}`；不回显 key |

- 重试只发生在对话轮内，不得无限重试；最终失败必须显式降级播报，不得静默弃轮。
- 401/403 视为凭据问题：点名"鉴权失败"，不重试，提示检查 key。
- 对话轮进入云链前有内部 SRAM 准入预算（24 KB，短等 1.5 s）：mbedTLS 只走内部
  SRAM，预算不足显式弃轮并点名 `内部堆预算不足`，不赌 `create_ssl_handle`。

## 5 凭据与日志

| 形态 | key 来源 | 禁止 |
|---|---|---|
| Pi 4B | secrets 文件（`keys.<ref>`）或 `env:变量名` | 编译进二进制、打印到日志 |
| ESP32-S3 / classic | NVS 键（与 WiFi 凭据同库） | 编译进固件、写进串口日志 |

- 日志只允许出现 `key_ref` 名称与"缺 key"结论，不允许出现 key 值。
- 面板维护密钥后**下一轮生效**，不要求重启。

## 6 mock 档（仅测试）

- `RR3_BRAIN_CLOUD=mock` 时三跳走本地替身：ASR 返回注入文本、LLM 返回固定回复、
  TTS 返回正弦 PCM。
- mock 只能用于单元/e2e 与台架；**单板全链验收必须是 real 档**，mock 证据不计。

## 7 固件移植约束

- ESP32 侧不引 `ureq`/rustls；用 ESP-IDF 自带 `esp_http_client` + mbedTLS。
- 请求体装配与应答解析走共享纯函数（W2 抽取的 `rr-cloud-proto`），传输层只做
  字节收发；三家请求字节与 Pi 侧对拍一致。
- 大响应（TTS PCM）走 PSRAM 缓冲；读体上限与超时同本页 §4。

## 8 一致性判据

1. 三家请求体字节由共享纯函数生成，Pi 与 MCU 对拍一致（除 `boundary` 随机值）。
2. 端点、字段名、`response_format=pcm`、`language=zh`、`filename="a.wav"` 逐项在本页在册。
3. 任何新增云能力（唤醒词、流式、function-calling）先改本页并过评审，不在实现里私开字段。
