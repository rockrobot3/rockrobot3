## A ESP32 双芯片烧录（classic / S3）

**前置**

1. 制品只取流水线产物（本地不构建）：release 资产或 ghcr 固件 OCI
   （`ghcr.io/rockrobot3/rockrobot3-firmware:<tag>`）。
2. 工具：`espflash` 4.6.x；串口设备已插好；烧录前确认 ELF 的 sha256 与发布清单一致。
3. 分区表与 bootloader 用发布包随带件（`partitions.csv` 由 `flash-artifact.sh`
   钉到工程真值；`--bootloader` 指同版 bin）。

**执行**

```bash
# 校验 + 烧录（不构建）；classic 与 S3 各跑一次
bash tools/deploy/flash-artifact.sh <app.elf> --chip esp32   --bootloader <bootloader-esp32.bin>  --monitor
bash tools/deploy/flash-artifact.sh <app.elf> --chip esp32s3 --bootloader <bootloader-esp32s3.bin> --monitor

# 启动日志采集（显式清 DTR/RTS，避免"ROM 日志后全是噪声"的假故障）
python3 tools/deploy/console-log.py -s 15 -o /tmp/rr3-<chip>.log
```

**判据（逐条进证据档）**

- 启动自证行：`console=uart0@115200 secondary=none`（S3）与控制台可读率。
- 六任务运行态：`/api/board/health` 六任务 `running`、`restarts=0`、`overruns` 不增。
- 网络与时间：STA 在线、`/api/board/health` 的 `"sntp":"synced"`（或 300 s 终判路径的点名）。
- 云链路（S3）：一轮 ASR→LLM→TTS 完成、`tts_played` 递增、`tts_fail=0`。
- classic：按既有 No-Go 裁定只验机制/探针面，不把全链写成 Go。

**失败归因入口**：`rrd` per-unit 日志目录、`/api/board/health` 快照、串口日志尾部。

## B ghcr 制品核验（digest / SBOM / 签名 / 拉回）

**前置**：正式 tag（`vX.Y.Z` 且与仓根 `VERSION` 同源）；发布 secrets 就位。

**执行**

```bash
# 五类制品总账（判据单点，批178）：一条命令核镜像三架构 + 固件 + distro + OTA + buildroot
bash tools/ci/lib/release-verify.sh --tag vX.Y.Z
# 注意 v0.0.8 是历史例外：OTA/buildroot 以无 v 名留存、distro 当时尚未发布——只核两类
bash tools/ci/lib/release-verify.sh --tag v0.0.8 --classes image,firmware

# 取合并清单与 digest（人工对表用；判据以 release-verify 为准）
docker buildx imagetools inspect ghcr.io/rockrobot3/rockrobot3:vX.Y.Z

# 证明面：单架构清单应各带 2 条 attestation manifest（provenance + SBOM）
for a in amd64 arm64 riscv64; do
  echo -n "$a attestations="
  docker buildx imagetools inspect --raw "ghcr.io/rockrobot3/rockrobot3:vX.Y.Z-$a" \
    | python3 -c 'import json,sys; d=json.load(sys.stdin); print(sum(1 for m in d.get("manifests",[]) if (m.get("annotations") or {}).get("vnd.docker.reference.type")=="attestation-manifest"))'
done

# 文件面 / 运行面两段冒烟（与 CI 同源）
bash tools/deploy/image-smoke.sh file ghcr.io/rockrobot3/rockrobot3:vX.Y.Z
bash tools/deploy/image-smoke.sh run  ghcr.io/rockrobot3/rockrobot3:vX.Y.Z

# 固件 OCI 标签与内容（classic safe / S3 full）
docker buildx imagetools inspect ghcr.io/rockrobot3/rockrobot3-firmware:vX.Y.Z
```

**判据**

- 合并清单含 `amd64/arm64/riscv64` 三架构；两段冒烟全过。
- 证明面：每条单架构清单带 **1 条 attestation manifest**，其内部两枚 in-toto 层
  分别声明 `https://slsa.dev/provenance/v1` 与 `https://spdx.dev/Document`
  （2026-11-27 匿名实测：v0.0.8 三条单架构腿均如此；合并 index 里则是每条腿各一条
  attestation 入口，共 3 条）。`release-verify.sh` 按**谓词层**判，不再数"≥2 条
  manifest"（旧口径与真实形状不符）。
- 签名：cosign keyless 已启用（2026-11-25，merge/firmware；2026-11-27 起 distro），
  按 B.1 的身份约束验证；未通过即红，不得记"未启用"。
- 取数失败（401/网络/包不可见）退出 2，按**未定**处理：先查凭据与包可见性，不得记成
  "缺件"，也不得跳过这一步宣称发布成功。
- digest 与发布回执一致。
- 拉回校验：在干净机器按 digest 拉取并跑 `image-smoke.sh file`。
- 固件 ELF sha256 与发布清单一致，烧录见 A。

**B.1 cosign 签名（2026-11-25 落册并接入）**

- **方案**：keyless OIDC（Sigstore Fulcio + Rekor），不引入长期私钥；签名身份由
  GitHub Actions 的 OIDC token 证明。
- **身份约束（验证时必须逐条匹配）**：
  - issuer = `https://token.actions.githubusercontent.com`；
  - identity 正则 =
    `^https://github\.com/rockrobot3/rockrobot3/\.github/workflows/publish\.yml@refs/tags/v[0-9]+\.[0-9]+\.[0-9]+$`
    （只认正式 semver tag 触发的 publish，不认分支、rc、手动 dispatch）。
- **签名对象**：merge 后的多架构 digest；三腿单架构 digest；固件 OCI 与 distro OCI
  tag 指向的 digest。一律按 `镜像@digest` 签，避免 tag 漂移。
- **验证命令（凭据窗口执行）**：
  ```bash
  cosign verify "ghcr.io/rockrobot3/rockrobot3@<digest>" \
    --certificate-identity-regexp '^https://github\.com/rockrobot3/rockrobot3/\.github/workflows/publish\.yml@refs/tags/v[0-9]+\.[0-9]+\.[0-9]+$' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
  ```
- **启用前置**：publish.yml 增 `permissions: id-token: write`；安装 cosign 后对
  merge digest 执行 `cosign sign --yes`；验证步骤在同一 job 内先跑一次反向用例
  （错误 identity 必拒），避免"签了但没验"。
- **当前状态**：**已接入（2026-11-25，merge 与 firmware 两条腿），待正式 tag 验证**。
  cosign 固定 `v2.6.5`，动作 `sigstore/cosign-installer@v3` 已登记进 ACTION_MATRIX；
  签名仅对 `refs/tags/v*` 执行，分支 edge 不签。v0.0.23 发布早于接入、未签名；
  下个正式 tag 跑通正/负两条验证路径后，回写本节与 status 行。

## C Pi 探针冒烟（A 组：线面/协议）

**前置**：Pi 直连板、`/dev/ttyAMA0` 空闲；先停常驻链释放 UART。

```bash
sudo systemctl stop rrd
python3 tools/pi-periph-probe/bw_probe.py B1500000 60      # 带宽/误码，60 s
python3 tools/pi-periph-probe/frame_probe.py B1500000      # 帧面 128B 头 + CRC32
sudo systemctl start rrd
```

**判据**：撕裂 0 / seq 断档 0 / CRC 不符 0 / 乱码 0B；`frame_probe` 的
`rr3.call` 六例逐条应答、`set_bindings` applied；帧偏移只读
`envelope_gen.py`（零手抄）。
