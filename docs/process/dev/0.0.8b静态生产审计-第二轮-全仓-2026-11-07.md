| # | 问题 | 证据 | 影响 | 修复 |

## 2 本轮复查后定性为安全的面（留档防重扫）

- **产码 panic 面**（75 处 unwrap/expect 逐点定性）：全部带真不变量或 fail-honest
  启动语义——`header.rs` 切片有长度前置守卫、`supervisor.rs` 的
  `jobs.get().expect` 有"children 键只来自 jobs"不变量、`audio_session` 的
  `find().unwrap` 与 `ok_reply_line`（`contains` 同串）恒中、`dialog` 预滚环
  `len>1` 守卫先于 `pop_front`。两处裸 unwrap（esp32 main `Peripherals::take`、
  topics_load 常量路径 parent）本轮收敛为带根因 expect。
- **锁中毒面**：产码统一 `rr3_lock`（`into_inner` 容忍中毒）；剩余
  `.lock().unwrap()` 全部在 `#[cfg(test)]` 段。
- **子进程参数源**：`systemctl reboot` 双重门（cfg(linux)＋`RR3_REBOOT_OK=1`）
  参数固定；`/usr/bin/say` 绝对路径＋显式档位；supervisor `Command::new(job.entry)`
  的 entry 经 manifest 层强制 POSIX 绝对路径；nmcli 凭据已过形制校验（第一轮）。
- **收窄转型**：`as u32/u16/i32` 全清单逐点在物理域内（电量 u8×10、INA219
  raw 右移域、PWM duty 反算 min..max 域、f64→u32 saturating）。
- **资源生命周期**：socket ACL 0600＋组门；未注册连接有 `pre_register_timeout_ms`；
  慢消费者 fan 队列由 watchdog 判死闭环（hang 模块不喂心跳被杀，队列随连接释放）；
  log ring、brain 预滚窗、counters 合并写均有界。
- **本地路径泄漏**：`git grep /Users/ /home/` 产码零命中（唯一命中是 secrets
  单测夹具的伪造 `/home/u`）。
- **tracked 产物**：620 文件零产物污染（本轮又物理清掉 9 个实录 wav、2 个
  `.DS_Store`、1 个 `__pycache__`，见 §4）。
