## 2 本轮扫描后定性安全的面（留档防重扫）

- **锁序/死锁**：全仓双锁候选逐点定性——`gate→shared` 方向有注释钉死且一致；
  contracts 锁各函数独立取放；esp32audio 单向 inner→ring；client 双锁均为顺序非嵌套。
- **板侧忙等**：`drain_outbox`/`drain_audio` 均为取空即退的排空循环；
  运行面空拍 `sleep(RUNTIME_TICK_MS)`；UART 读带 `LINE_BYTE_TICKS` 超时。
- **板侧队列**：`audio_q` 有界（`AUDIO_Q_CAP=4` 丢最旧＋计数）；outbox/jobs
  生产者速率受行预算与宿主 RPC 节律约束，排空优先，实际有界。
- **除零**：配置驱动除数（`sample_rate_hz`、`window_ms`）均有显式 0 守卫；
  其余除数为编译期常量。
- **brain 云面**：ureq 超时档＋有界重试（上限 2×timeout）；心跳独立线程，
  主循环阻塞不触发误杀。
- **错误吞没**：产码 `let _ =` 集中在 Drop/测试清理；关键通道失败均有留痕或
  降级点名。
- **桩面**：`todo!/unimplemented!/TODO/FIXME` 产码零命中。
