## 定性边界（不限修复，供后续裁决）

1. **客户端 connect 无超时**（`rr-bus-api/client.rs` L292、`uds.rs rr3_connect`）：UDS 死路径立即
   ECONNREFUSED；仅"守护在听却不 accept 且 backlog 满"时可能阻塞。std 无 UDS connect-timeout 构造
   （TCP 才有 `connect_timeout`），需 libc 非阻塞 connect＋poll——K5 依赖预算裁决前维持现状，
   注册 RPC 的 `RR3_CONNECT_TIMEOUT` 是 connect **之后**的语义，非隔离 connect 本身。
2. **本地进程连接洪泛**：unregistered 连接受 `pre_register_timeout_ms` 定时回收，注册面受 16 上限；
   瞬态（rate × timeout）线程峰值在"可信局域网单操作者"威胁模型外。
3. **socket ACL 放行失败降级**（`rr3_socket_acl_grant`）：chmod 失败留 umask 权限并点名，
   chgrp 目标组不在位留 root:root 并点名——"紧权限敞口比守护起不来轻"的既定裁决，维持。
