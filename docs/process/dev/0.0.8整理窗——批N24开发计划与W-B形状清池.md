## §2 立册裁定（机制/策略分离＋零行为改变两红线）

1. **错型枚举化**：mech 机制层返回**零堆结构化错误枚举**（携带 `&'static str` 或
   `Rr3HalError` 数据，纯数据零分配）；composite 编排层负责 `format!` 人读文案渲染
   （策略）——机制返回事实、策略渲染文案，文件级机制/策略分离同批N23 口径。
   **文案逐字保持**＝零行为改变判据（枚举数据渲染出的错误文案与现 String 版逐字一致，
   单测断言钉原文；先例＝face.rs :97 契约投影对账）。
2. **`&mut dyn` → 泛型**：`rr3_relay_apply` gpio 参数、`rr3_tts_play` sink 参数改
   `impl Trait`/泛型形参（act 册 :152 判定原文"bare 禁 `dyn` → 泛型"——单态化不改行为）；
   两 trait 错型已是零堆契约枚举 `Rr3HalError`（rr-hal-api :264-265），泛型无需新增 bound。
3. **wifi 凭据值类型化**：`credentials: Option<(String, String)>` → `Option<Rr3SsidText>`
   ——**pass 在 mech 内零读者**（只写不读：wifi/mech.rs :88 唯一写点、无读点；"本状态机
   只管态不管存"MC-6 语义原文，pass 持久化由后端承载）→ 去除 pass 死重量存储不改行为、
   头注如实注记；`rr3_provision_connect(&mut self, ssid: &str, pass: &str)` 与
   `rr3_provision_restored(ssid: &str)` 入参改 `&str`（撤 composite.rs :359 的
   `ssid.clone()`）；SSID 存储复用契约面值类型 `Rr3SsidText`（rr-hal-api :93，与
   connect 册 :171"值类型侧结"同一真值点）。
4. **face join 常量化**：`RR3_FACE_EXPRESSIONS.join("/")` 四处（face/mech.rs :669＋
   composite.rs :668/:742/:760，全在错误文案渲染）改 `'static str` 常量投影＋对账单测
   钉死（常量串与数组逐名一致，防漂移——先例同 §2-1）。
