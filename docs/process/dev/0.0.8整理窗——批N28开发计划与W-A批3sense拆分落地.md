## §2 裁定

1. **composite.rs 消解三落点**（语义零改动，逐字迁）：
   - `main.rs`（装配层，≤80 行）：SURFACE 启动自述（capture→vad→env→imu 四原子 chain，
     序不变）→ `bootstrap`（Rr3ModConfig{config_env=Some("RR3_SENSE_CONFIG"),
     parse_config=boot::rr3_sense_config_parse}）→ config 就绪行（「config 就绪: 来源=
     {path} doa_bin_threshold_deg={} doa_window_ms={} doa_window_rms_min={}
     doa_mic_baseline_mm={}」逐字；path 经 rr3mod `rr3_config_path` 投影，见裁定 6）→
     `boot::rr3_sense_probe`（音频源探活编排）→ Dispatcher 构造 → `serve(bus, &mut
     dispatcher, Duration::ZERO)`（§2.6 归一，poll_wait=ZERO）。
   - `boot.rs`（接入层）：`rr3_sense_config_parse`＋`Rr3SenseConfig`/`Rr3DoaConfig`/
     `Rr3ReflexConfig`＋Default＋`rr3_cfg_u64`/`rr3_cfg_i64`/`rr3_cfg_bool` 三 helper＋
     5 config 测（Rr3AudioConfig/Rr3VadConfig 等 atoms 类型经 `crate::capture`/`crate::vad`
     路径引用，`#[path]` 声明随 main.rs）＋音频源探活编排 `rr3_sense_probe(cfg)`：
     `rr3_hal_audio_source_with_cmd()` 选择＋反射环旁路警告行（「rr3-sense: 反射环已启用
     但后端 {backend} 无命令旁路…（仅 esp32 档承载）」逐字）＋open_cfg 按 config 真值
     构造＋`source.open(open_cfg)`（失败「打开音频源({backend})失败: {e}」Err 上抛）＋
     「音频源就绪: backend={backend} rate={} ch={} frame_ms={}」回显，返回
     `(source, cmd_tx, backend, open_cfg)` 四元。RR3_SENSE_CONFIG_ENV 常量退役
     （归 config_env 实参，方案树自注照做）；RR3_MANIFEST_ENV 本地常量退役（bootstrap 承接）。
   - `rpc.rs`（协议层）：载荷组装五函数逐字迁（`rr3_pcm_event_body`/`rr3_doa_field`/
     `rr3_vad_event_body`/`rr3_dump_result`/`rr3_sense_ops_snapshot`）＋6 测（载荷 4＋
     dump/ops 2）。
   - `dispatch.rs`（机制层注册面）：`Rr3SenseDispatcher` 十三字段（裁定 2）＋`on_tick`
     ＝采集循环体函数化（方案 `rr3_capture_tick` 意图落本层：start 取 on_tick 的 now
     实参→read（buf 按"帧×声道"分配、欠载截断，失败「读帧失败({backend}): {e}」Err
     上抛）→doa_ring feed（双麦下混**前**入 ring）→`rr3_pcm_downmix_stream`→空帧记账
     →publish pcm＋`pcm_frames` 计数→VAD 边沿（门开弃 onset 计数＋回显逐字／onset DoA
     整窗回看判向／vad_start 发布／反射环 onset 存 pending 判停经旁路下发＋计数＋回显
     逐字，espidf 档 pending take 即弃 cfg 门照抄）→余量睡眠 `tick - spent`）＋
     `on_event`（tts_pcm 帧喂门控，非该主题忽略）＋`on_rpc` 三臂（dump→快照体／
     ops/list→`{"ops": 快照}`／兜底→Err 点名文案，serve 折 `{"error": e}` wire 等价）＋
     机制切片四件逐字迁（`rr3_pcm_downmix_stream`/`Rr3TtsGate`/`rr3_reflex_pan_target`/
     `Rr3DoaRing`）＋6 测（下混 1＋门控 2＋反射 1＋ring 2）。
   - atoms capture/vad/env/imu 四件原位不动（`#[path = "../atoms/…"]` mod 声明随
     main.rs 保留）。
