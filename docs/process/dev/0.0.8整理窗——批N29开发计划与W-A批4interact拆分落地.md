     本地常量退役（bootstrap 承接——interact 无「来源=」回显，main 不读 manifest_path，
     缺 env/读失败文案由 bootstrap 逐字同源承担）；RR3_INTERACT_CONFIG_ENV 常量留

     （裁定 7）。
   - `boot.rs`（接入层）：`rr3_interact_config_parse`＋`Rr3InteractCfg`/`Rr3PlayerCfg`/
