1. **rr3mod API 面现状**（base/runtime/rr3mod 762 行）：公开面七项——`RR3_MANIFEST_ENV`/
   `Rr3ModConfig<C>`/`bootstrap`/`load_config_text`/`rr3_config_path`/`BusHandle`/
   `Dispatcher`＋`serve`；依赖面＝rr-bus-api/rr-ipc/rr-core＋serde_json，全部 Rust 侧可用；
   `#[cfg(unix)]` 门与 rr-bus-api 同形状；**六消费方同批改纪律**（五模块＋brain 迁移件，
   方案 §5 批0 附加纪律）——本批件二接入即第六消费方正式入列。
2. **brain 现状树**（modules/rr3-brain，Python 1587 行）：`rr3_brain` 包六件（bus 431/
   composite 478/dialog 110/intent 78/cloud 三件 333/__main__ 14/__init__ 24）＋tests 七文件
   ＋pyproject.toml＋config.toml 四段（cloud/model/bus/dialog）＋module.toml；atoms 四目录
   （asr/dialog/llm/tts）与 composite.toml 装配申报在案。
3. **brain 编排面现状**（composite.py 主循环 `rr3_brain_run`）：事件面两臂（`rr3-sense/audio/pcm`
   积累／`rr3-sense/audio/vad_start` 判停触发整轮）＋节拍面一臂（`rr3_utterance_expired`
   时长判停触发整轮，`max_utterance_ms` 封顶）＋RPC 面三臂（`llm/completion`、`ops/list`、
   `ops/set`＋未知 topic 兜底 `{"error": …}` 应答）；`rr3_finish_turn`＝ASR→LLM→TTS→
   分帧发布 tts_pcm→interact 点名→intent 发布→record→计数，**业务失败折日志弃轮进程不死，
   传输失败 exit(1) 交 supervisor**（与五模块同一契约）。
4. **BusHandle API 覆盖核对（全量通过）**：brain 总线操作六种逐一对上——`rr3_publish`↔
   `BusHandle::publish`、`rr3_call_topic`↔`BusHandle::call`（timeout 显式实参，批N25 裁定 2）、
   `rr3_counter_bump`↔`counter_bump`（Rust 多 `by: u64` 实参，Python 单参 bump 1 即可）、
   `rr3_connected`↔`connected`；`rr3_poll_wait`/`rr3_reply_call` 由 serve 骨架内部承载不进
   Dispatcher 视野（五模块同构）；name/task 回显由 bootstrap「总线就绪」一行打印。**零缺口**。
5. **语义差一笔（启动序，B-13①）**：brain 现状 **config 先于总线连接**（composite.py :248-256
   注记明示——`connect_timeout_s` 是连总线的参数，缺文件/坏键在连接前拒）；rr3mod bootstrap
   固定序＝读 manifest→`rr3_connect`→打印总线就绪→`load_config_text`→parse（boot.rs :18-29）。
6. **`connect_timeout_s` 消费点核实**：Python 侧 `rr3_bus_connect(…, connect_timeout_s=5.0)`
   透传注册帧等待上界（bus.py :205/:238/:431）；Rust 侧 `rr3_connect(manifest_text)` **无超时
   参数入口**（client.rs :261，连接/注册等待由 rr-bus-api 内部承载）——该键在 Rust 侧无落点。
7. **config 路径对位核实（等价成立）**：Python 缺省＝包上一级 config.toml（composite.py :83
   ＝`modules/rr3-brain/config.toml`）≡ Rust 缺省 manifest 同目录（boot.rs :56-63；装配实况
   manifest＝`modules/rr3-brain/module.toml`）——同指一文件；env 覆盖 `RR3_BRAIN_CONFIG`
   （composite.py :81）↔`Rr3ModConfig.config_env = Some("RR3_BRAIN_CONFIG")`。
8. **HTTP/TLS 依赖面核实**：brain cloud 用 stdlib `urllib`（HTTPS——api.siliconflow.cn/
   api.deepseek.com）＋base64/uuid/math/struct；**仓内零 crates.io 网络栈先例**（全仓
   Cargo.toml/Cargo.lock grep 零命中 ureq/reqwest/minreq/base64）；panel `server.rs` 是手写
   HTTP/1.1 **服务端**且明示不做 TLS（局域网可信面声明）——云端 HTTPS **客户端**无 std
   手写可能（TLS 必须库承载）。mock 路径（`RR3_BRAIN_CLOUD=mock`：ASR 固定文本/LLM 回显/
   TTS 正弦 PCM）纯 std 可实现、不走 HTTP。
9. **Dispatcher 语义两档对位（直接承载 brain 失败契约）**：on_rpc 返 Err＝业务性失败折
   `{"error": …}` 应答；on_event/on_tick 返 Err＝传输性/设备级失败上抛致命——brain 业务失败
   （云端 4xx/5xx、空文本、被调方超时）在臂内折日志弃轮返 Ok，传输失败返 Err 上抛，
   ADR-0016 裁定 2.2 不变量零新增语义。
10. **测试面现状**：brain tests 七文件（unittest 体系）；ADR-0016 裁定 2.3＝unittest→cargo
    test 换轨、条数随迁移批次登记 conventions §2、brain-unittest CI job 随**最后一件**迁移
    同步退役；`which_python3` 能力验证面与 brain shim 随最后一件退役（裁定 3 原义）。
11. **部署形态兑现清单**（裁定 3，随件四核对）：module.toml `lang` 改 rust、e2e 装配单 brain
    entry 指真二进制（shim 退役）、deb/rootfs 去 python3 运行时（Buildroot defconfig 核对）——
    「不以件为单位、以仓库终态为准」，件四只兑现码面可见项，打包链核对如实登记。
12. **部署与命名先例**：brain crate 独立 workspace（同 rr3-interact 形制，吃不到 base/runtime
    继承）；module.toml 红线 1 exposes 零改动（三 RPC＋两发布＋两订阅申报面不动）；check.sh
    九步门禁对 brain 迁移件一视同仁（裁定 2.3）。

## §2 裁定（八条）

1. **评审结论（API 面无缺口）**：rr3mod API 面经逐面对表（取证笔1/4/7），brain 迁移件可全量
   消费，**无"Python 侧不可用"依赖**——0.0.8 方案 §8 DoD ⑤ 兑现，随本件勾选。
2. **Dispatcher 形状（§7 点名裁定）**：brain 迁移件 Dispatcher 三入口对位——on_event 两臂
   （pcm 积累＋vad_start 判停触发；topic 本地过滤，rr3mod 不提供 subscribe 是设计）＋
   on_tick 一臂（utterance_expired 时长判停；poll_wait 250ms 对位 Python 主循环 0.25s，
   作 serve 实参由装配段定）＋on_rpc 三臂＋兜底（completion/ops/list/ops/set；未知 topic
   返 Err 由 serve 折 `{"error": …}`，与 Python 现状同 wire 等价）。**ASR/LLM/TTS 编排
   （`rr3_finish_turn` 对位）挂两路共用**：on_event vad_start offset 臂（语义判停）＋
   on_tick expired 臂（时长判停）——与 Python 主循环两触发点同构，单一编排函数两入口，
   不复制编排面。
3. **错误两档对位（裁定 2.2 不变量承载）**：取证笔9 口径——业务失败臂内弃轮返 Ok、传输
   失败返 Err 上抛致命；on_rpc 业务失败返 Err 折 error 应答。同步阻塞语义如实登记：整轮
   （云端 HTTP＋interact 播放点名）阻塞 serve 主循环＝Python 既有形状（主循环内联
   finish_turn），迁移不引入新语义。
4. **启动序与 `connect_timeout_s`（B-13① 语义差裁定）**：brain 迁移件**遵 rr3mod bootstrap
   固定序**，不为单一消费方改骨架顺序（六消费方同批改纪律；机制与策略分离）。代价两条如实
   登记：①config 坏键失败时序后移（先注册后拒），退出语义不变（exit(1) 交 supervisor），
   fail-closed 性质不变；②`[rr3-brain.bus].connect_timeout_s` 键**随迁移退役**——它是
   Python 承载侧注册帧等待上界的注入口（B-13① 数据化对象），Rust 侧 `rr3_connect` 无该
   参数入口（上界由 rr-bus-api 内部承载），键留无消费点即死键病形（0.0.5 批I B-2 先例：
   死参数必删、留键误导）。`call_timeout_s` 保留（`BusHandle::call` timeout 显式实参有
   消费点）。键退役随迁移件施工落 config.toml 注记＋bus 册 B-13① 行注记；裁定 2.4「键名
   逐键对照」意图（防丢配置语义）不受损——键的消失是承载点变化的诚实结果，随批登记。
5. **HTTP/TLS 依赖选型方向（件三前置）**：brain crate 引入仓内首个网络栈 crates.io 依赖，
   方向＝**同步 API＋rustls 系**（零异步栈——本仓全同步面，reqwest 异步栈不取）；TLS 必须
   库承载（panel 手写 HTTP 仅局域网服务端先例，不适用云端 HTTPS 客户端）；mock 路径纯 std
   零 HTTP。具体 crate/版本归件三 Cargo.toml 施工落；base64/uuid 对位以「最小依赖面」为
   准绳逐项核对（std 可手写则不引 crate）。
6. **评审性质与登记**：本评审＝ADR-0016 增补评审（细化首裁裁定 1/2 的实施形状，不改已裁
   内容；[ADR-0016](../adr/ADR-0016-brain迁移路线-python转Rust渐进首裁定.md) 文末修订记录
   加指针行——0.0.6 Q1 修订先例同形）；裁定行落 decisions §2 表尾（取证基线 `6add250`）；
   **ADR-0014 不增补**（首裁「明确不做 2」原义：其裁定 2/3 云 API 形状与对话回路归属继续
   有效，直到迁移件按裁定 2 逐语义对照通过）。
7. **件表五件**（每件一提交推三远端，全中文提交信息）：件一立册＋增补评审（本件，纯文档）；
   件二＝迁移件 1——brain crate 立树＋总线壳＋事务面（bootstrap+serve 接入＋Dispatcher
   on_rpc 三臂：ops 两臂全语义＋completion 兜底＋config 解析面三纯函数迁移；bus.py/
   test_bus.py 退役时点随裁定 8 改判件四）；件三＝迁移件 2——cloud 三客户端 Rust 化
   （mock 三件＋completion 臂激活；cloud/*.py 退役）；件四＝迁移件 3——dialog/intent＋
   on_event/on_tick 编排＋composite.py/__main__.py/bus.py/test_bus.py 退役＋最后一件收尾
   动作（pyproject 退役/module.toml lang=rust/shim 与 which_python3 退役/brain-unittest
   CI job 退役——裁定 3 部署形态码面兑现）；
   件五＝收口对账（decisions §4 收口行＋conventions §2 登记＋本册 §4 核销＋复验）。
   迁移期间「半 Python 半 Rust」过渡态＝首裁负面后果预告的既定形状；切分纪律＝迁移件与
   Python 对应物同批一进一退，仓库任何时刻不存在同一语义双语言真值。
8. **bus.py/test_bus.py 退役时点（件二→件四，件二开工对表改判）**：裁定 7 件表原裁
   bus.py/test_bus.py 随件二退役；开工对表三证据改判——①composite.py :39-45
   `from rr3_brain.bus import …` 硬依赖，件二退役 bus.py 即打断过渡态进程装配；②tools/sim
   brain 演练（`--brain`）起真 Python brain 进程跑四真进程闭环（云端 `RR3_BRAIN_CLOUD=mock`），
   件二退役即断 sim 演练运行面；③CI brain-unittest job 跑 test_bus.py（裁定 2.3：job 退役
   随最后一件迁移）。改判依据：bus.py 是 rr-bus client.rs 的声明镜像——总线协议真值单点
   在 rr-bus/rr3mod（既有码面），过渡态保留不新增双语言真值；退役随件四与 composite.py/
   __main__.py 一并（同批一进一退纪律不变，裁定 7 件表相应两格同笔修正）。
