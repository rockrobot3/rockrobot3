## 2 结论与不涉面

- DoA 当前不可用作验收：声学 SNR 太低（喊声仅比底噪高 0–70%），xcorr 主峰多在噪声里；
  需要改善站位/距离（20–30cm、45° 左/中/右）、提高喊声或调整板麦增益/摆位后重跑。
  本轮**不改** DoA 算法、固件增益或 OLED 自愈策略（待现场证据/裁定另批）。
- OLED“亮不亮”不是 I2C 地址/扫描问题：两次启动都扫到 0x3C 且 init 一次过；黑屏时改用稳定 USB 供电即恢复。
  遗留的“无绑定→自愈恒跳过”属部署形态缺口（音频独占 UART 时无人推 `rr3.set_bindings`），登记待修。
- P0-A U3 对拍必须先回烧旧固件取基线，再做新固件同脚本对拍；旧版抓取含音频帧，不能当基线。
