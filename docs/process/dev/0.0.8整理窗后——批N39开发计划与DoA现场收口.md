## 2 结论与不涉面

- DoA 分侧 3×10 **已通过**：左首轮 6/10（7 有效）未过，重测 8/10（8 有效全对）；中 10/10
  （原始因固定偏置 -1.115 判 1/10，偏置校正后 10/10）；右 10/10。方法＝xcorr 主峰分数 lag
  + 镜像映射 + 中段零位偏置 + 中位死区 ±0.7；中段同时作零位标定（工厂式），左右为 held-out
  验证。证据 [实测/0003](../../evidence/实测/0003.md)。本轮**不改** DoA 算法/固件增益/OLED 自愈策略。
- OLED“亮不亮”不是 I2C 地址/扫描问题：两次启动都扫到 0x3C 且 init 一次过；黑屏时改用稳定 USB 供电即恢复。
  （黑屏的直接诱因＝充电宝供电质量；`selfheal_skip` 仅解释“不恢复”，不是 init 失败原因。）
  遗留的“无绑定→自愈恒跳过”属部署形态缺口（音频独占 UART 时无人推 `rr3.set_bindings`），登记待修。
- P0-A U3 对拍必须先回烧旧固件取基线，再做新固件同脚本对拍；旧版抓取含音频帧，不能当基线。
