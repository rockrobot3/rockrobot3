- **语义（用户 2026-11-02 澄清）**：classic 是**无完整系统底座依赖的快速部署验证**；ESP32-S3、当前 Pi 4、后续 RK3566 都是**可独立运行的平台**。组合形态（Pi 宿主 + 板末梢）与独立平台形态的装配单不得混用。

## 1 平台矩阵

| 形态 | profile | 说明 |
|---|---|---|
| Pi4 + classic 快速部署 | `pi4b-host-esp32-classic.toml` | classic 板只做末梢（I2S 麦 / LEDC 双轴 / I2C OLED / UART2）；Pi 跑完整底座，用于快速验证 |
| Pi4 独立 | `pi4b-host.toml`（N44 已立） | host-only（本地 MAX7219/USB 声卡）；`pi4b-host-esp32-classic` 是带 classic 板组合，不等同 |
| Pi4 + S3 | `pi4b-host-esp32s3.toml` | S3 独立平台组合；板侧 41/42、8/9、4/5、6/15/7、1 |
| S3 单板 | `esp32s3-mini.toml` | 板侧独立固件 |
| RK3566（未来） | `default.toml` / `distro.toml` | 两档 chip 均为 `rk3566`（现成） |

> **2026-11-06 N44 起**：Pi 装机默认已从 classic 切到 `pi4b-host.toml`
> （`profile.conf.bak-n44` 备份；drop-in 显式 `RR3_HAL_BACKEND=linux`）；
> classic 档保留为组合形态，不再作为本机默认。
