### 1.1 N43-1 审查裁定（2026-11-02）

计划原文两处与现有机制冲突，开工前逐条核过并改判；判据 = 现有 `check.sh` 必须绿、
且不把单轴宿主能力伪装成双轴：

1. **`pi4b-board.toml` 档位 host → rtos（薄板端点档）**。host 档 rrd 会把 `[[pin]]`
   派生进唯一的 `Rr3HalBindings`（一组 `pwm_chip`/`pwm_channel`，对应 rr3-act 的单轴
   `Rr3PwmServo`），而 W4 板必须成对登记 pan/tilt：同 chip 双通道 → `pwm_channel`
   两值相冲；双 chip → `pwm_chip` 两值相冲——派生面的"多实例共键须同值"两路皆红。
   rtos 是 esp32-mini/esp32s3-mini 同款的"薄板经桥"档，rrd 不派生、板侧按 `[[pin]]`
   自行装配；W4 的 Pi 正是板，Mac 宿主在 W5 走 `--brain`（§10.1）不读装配档。
2. **`distro.toml` 补 tilt 撤登**。distro 是 host 档参考机装配单，受同一单轴描述符
   约束；加第二枚 `act.axis.pwm` 会让既有 `distro_profile_wiring_drill` 当场红。
   Pi 板双轴真值改由 `pi4b-board.toml`（rtos）承载；distro/default 保持单轴宿主能力
   的诚实表达。
3. **Pi tilt 词形：pwm0/channel 1，而非控制器 `pwm1`**。BCM2711 的 `pwm-2chan`
   落成 `pwmchip0` 下的 `pwm0`/`pwm1` 两个通道目录；平台表 `pwm0 channels = 2`
   已按此登记。计划 §9.2 的 "pwm1" 按 sysfs 通道目录名理解，不另立第二颗 chip。
   （RK3566 的"每通道一 chip"语义不同，不在此档复用。）

落地面：`profiles/pi4b-board.toml`（pan=pwm0/ch0/GPIO12，tilt=pwm0/ch1/GPIO13，
rail5v/release，`act.servo` 单格）、`hardware/pi4b-board/wiring.toml`（J-UBEC +
J-PAN + J-TILT，SG90-3P 对表）、`contracts/platform/raspberry-pi-4.toml`
`[construction]` 两枚 `sysfs-pwm`；校验①②⑨ 由 rrd 新 drill
`pi4b_board_profile_boot_inputs_drill` 与 rr-registry 形状 pin 双向机判。

## 2 硬件前置（N43-4 才需要）

| 件 | 用途 |
|---|---|
| CP2102 USB-TTL | Pi UART2 ↔ Mac 宿主；classic 板自带那只留给板载 console |
| ADS1115（0x48） | Pi 板侧 5V 轨压，A0 + 2×10k 分压 |
| 5V 3A UBEC | 舵机独立供电，禁接 Pi 5V，单点共地 |
| SSD1306 0x3C + SG90×2 | Pi 板侧 OLED/舵机（若沿用 classic 板件需重新接线） |

无上述件时 N43-2/N43-3 仍可完成（单测＋无器件 Err 契约）；N43-4 挂起如实登记。
