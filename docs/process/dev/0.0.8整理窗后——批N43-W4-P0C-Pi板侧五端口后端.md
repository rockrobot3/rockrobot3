## 2 硬件前置（N43-4 才需要）

| 件 | 用途 |
|---|---|
| CP2102 USB-TTL | Pi UART2 ↔ Mac 宿主；classic 板自带那只留给板载 console |
| ADS1115（0x48） | Pi 板侧 5V 轨压，A0 + 2×10k 分压 |
| 5V 3A UBEC | 舵机独立供电，禁接 Pi 5V，单点共地 |
| SSD1306 0x3C + SG90×2 | Pi 板侧 OLED/舵机（若沿用 classic 板件需重新接线） |

无上述件时 N43-2/N43-3 仍可完成（单测＋无器件 Err 契约）；N43-4 挂起如实登记。
