8. **平台缺口补腿**：riscv64 发布镜像、S3 固件 release 资产——各需 tag/dispatch
   回执面；Windows 侧剩余独立工程须先具备非 Unix 编译面（理由已入矩阵）。
9. **esp32 分压遥测**：已裁非必做项（[decisions E-1](../decisions.md)）——不排期、
   不进发布门；仅在板上接线变化时按"只观测"口径复核。

## 4 纪律

- **分支范围**：只同步、提交、推送 `dev/hubs-01`；`main` 落后是常态，不合并、不推送；
- 每件一个 commit，推 origin/github/gitcode 三远端的 `dev/hubs-01`，核对三指针；
- 每件收口跑 `check.sh` + `metrics.py`；涉 `base/os/buildroot/**` 的改动必须确认
  没有在跑的全量构建（并发组 `cancel-in-progress` 会取消它）；
- 指标红线：重复率 ≤3%、CC 均值 ≤2.50、最大 ≤11、panic ≤73、长名 0、长睡 0；
- 不伪造板上证据：所有"已收口"必须带本机或 CI 可复核的回执。
