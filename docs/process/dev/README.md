# dev —— 版本档案卷首索引

本目录按**版本目录 + 统一命名**组织（2026-11-25 批46 裁定）：每个版本一个目录
（`0.0.1/` … `0.0.8/`），目录内文档标题一律以 `<版本号>版本` 或 `<版本号>增补轮N` /
`<版本号>实现窗` / `<版本号>整理窗` 起头，不带尾部日期；同一版本内的专题再分子目录
（增补轮六 / 实现窗 / 整理窗 / 整理窗后 / 单板全链 / 无硬件开发 / 静态生产审计 /
回执归档）。正文只增不改写——收口对账与实况一律看 [`status.md`](../../status.md)。

**版本口径**：仓根 [`VERSION`](../../../VERSION) 是唯一真源，当前 `0.0.8`；旧的高号
tag（0.0.9–0.0.23）已归档为 `archive/v0.0.x/*`；`v0.0.8` 为治理后首个发布点
（2026-11-26），下一次从 `v0.0.9` 起。版本纪律与发布点执法见 [conventions §7](../conventions.md)。
