# 真件装配与标定手册（0.0.5 增补轮四 批W5 / 全案 D9）

- **定位**：BOM 八行定案器件（R22）的**到货桌面级验收、单件装配与标定 runbook**——每件
  四件套（操作步骤→预期输出→判定标准→失败处置），到货即照单执行，不被任何未核对的
  器件细节卡住真件档（0.0.6 批F5）与 0.0.7 批C④。
- **权威边界（引用不複述）**：器件型号唯一权威 = [0.0.6 方案 §5.4](0.0.6版本洛克三号树莓派验证方案.md)
  R22 BOM 定案表（"到位状态"列在彼表维护）；装机接线唯一权威 = 同方案 §5.5.2 接线手册
  （六列表 + 整机供电拓扑）；板上软件配置件 = §5.5.3；逐链验收 = §5.5.4。本手册只管
  "件从快递盒到可用"这段，**到货型号与 BOM 定案不符时：先改本手册与 BOM 表，再装配**
  （差异登记进修订记录）。
- **通用纪律**：所有接线整机断电下进行；多电源系统**先共地再上电**（§5.5.2 断电接线
  纪律）；万用表常备；**3.3V TTL 器件严禁接触 5V**（ESP32/树莓派 GPIO 毁坏不可逆）。

## 件1｜USB 麦克风阵列（BOM #1：PS3 Eye 或同级 ≥2 麦多通道 UAC）

**到货复核**：USB IF UAC 1.0 标准类（Linux 免驱的前提）；麦克风阵列 ≥2 麦多通道。
普通 USB 单麦（笔记本级拾音头）**无声源方向信息，DoA 真件档不可达**（R14 硬约束），
单通道输出或不可关降噪的模组同判不符。

- 操作步骤：
  1. 插板上 USB 口，`arecord -l` 与 `cat /proc/asound/cards` 看卡是否在表；
  2. 多通道抓样：`arecord -D hw:rr3mic -c 4 -f S16_LE -r 16000 -d 2 /tmp/test.wav`
     （卡名未做 udev alias 前用 `hw:<card#,device#>`）；
  3. 非全零核验：`od -A d -t d2 /tmp/test.wav | head -20` 见非零样本（室内环境声即可）；
  4. udev alias 固定卡名后复验 `arecord -l` 显示 `rr3mic`（alias 配置见 §5.5.3 件 3）。
- 预期输出：卡在表；wav 文件 ≈256KB（16000 × 2B × 4ch × 2s）；样本幅值非全零。
- 判定标准：≥2 通道 UAC 可采（16bit/16kHz）；样本非全零；卡 id 固定为 `rr3mic`。
- 失败处置：声道数不足 / 不可关降噪 / 需私有驱动 → **退换货口径**（硬约束，R14/R22）；
  卡号漂移 → udev alias 修复；录出全 0 → 麦克风静音孔/增益档检查后复测。

## 件2｜SG90 舵机 ×2 + UBEC 独立供电轨（BOM #2/#3）

**到货复核**：UBEC 输入档位必须覆盖 **1S（3.0–4.2V）**、输出 5V/3A——2S 及以上输入
档位的 UBEC 接 1S 电池组**欠压不工作**（硬约束）；SG90 行程标称 0–180°。

- 操作步骤：
  1. UBEC 空载输出电压：万用表直流档量输出端，5.0V ±0.25V；
  2. 按 §5.5.2 接线 1 装配：舵机电源走 UBEC 5V 独立轨（**禁接 Pi 5V**——堵转峰值
     ~700mA/只，Pi 5V 轨带不动），UBEC GND 与 Pi GND **单点共地**（否则 PWM 无参考电平）；
  3. PWM 行程三点核对（板上 `sysfs` PWM 或 rr-hal linux 后端，50Hz / 周期 20ms）：
     duty 0.5ms → 目测 0°；1.5ms → 90°（中位）；2.5ms → 180°。
     sysfs 口径：`echo 0 > /sys/class/pwm/pwmchip0/pwm0/enable` 后依次
     `echo 500000 > duty_cycle`（0°）/ `1500000`（90°）/ `2500000`（180°），
     `period` 固定 `20000000`；
  4. 堵转电流核对：万用表电流档串入舵机红线，轻阻尼输出轴读峰值；
  5. 供电余量核对：双舵机同时满摆 + Pi 正常负载，UBEC 输出电压跌落 ≥4.75V。
- 预期输出：三点行程对应 0°/90°/180°（目测 ±5°）；堵转 ≤~700mA/只；带载电压达标。
- 判定标准：行程三点全对；UBEC 带载 ≥4.75V；堵转峰值与 3A 轨余量匹配（2×0.7A ≪ 3A）。
- 失败处置：输出轴抖动 → 共地单点检查（地环路是抖动常见根源，§5.5.2 接线 5）；
  行程角漂 → duty 换算复核（0.5–2.5ms ↔ 0–180° 线性）；UBEC 无输出 → 输入档位不符
  （欠压保护），退换 1S 输入档；行程只有 ~120° → 属 SG90 常见个体差异，以实测
  min/max 脉宽记录进本手册该件"复核差异"行。

## 件3｜MAX7219 LED 点阵（BOM #4 定案件，SPI）

**到货复核**：SPI 接口模块（MOSI/CLK/CS 三线 + VCC/GND 五针）；SSD1306 OLED 为存档
备选（R22），到货错型即按 BOM 表处置。

- 操作步骤：
  1. 按 §5.5.2 接线 4 装配（MOSI 19 / CLK 23 / CS 24，VCC 取 5V 轨）；确认
     `dtparam=spi=on` 已使能且 `/dev/spidev0.0` 存在；
  2. 初始化序列核对（仅验货用 python3-spidev 片段；实装走 rr-hal 显示后端）：
     decode mode 0（`09 00`）→ intensity 中档（`0A 03`）→ scan limit 全行（`0B 07`）→
     正常工作模式（`0C 01`）→ 关显示测试（`0F 00`）；
  3. 出帧核对：逐 digit 写 8 行行值——帧面与 HAL 事实源 `Rr3FaceFrame = [u8; 8]`
     一致（行字节 MSB 在左，与点阵列位序对齐）；例帧
     `[0x3C,0x42,0x81,0x81,0x81,0x81,0x42,0x3C]`（圆环）逐行写入后目测；
  4. 单点扫描核对：`0x01,0x02,0x04,…,0x80` 逐行单点移位，确认无行/列粘连。
- 预期输出：圆环帧完整显示、无错行错列；单点扫描 64 点各就各位。
- 判定标准：写入帧位图与点阵亮灭**逐行一致**（帧面语义与 `Rr3FaceFrame` 对齐）。
- 失败处置：全黑 → CS 线/供电/SPI 未使能逐查；全亮或字形错乱 → decode mode 未清零
  或字节序反（MSBfirst 确认）；局部半亮 → intensity/供电电流裕量检查；多片级联模块
  首片地址即设备 0，帧序按级联链方向写。

## 件4｜电池组 + TP4056 充电管理（BOM #6）

**到货复核**：TP4056 充电板**必须带保护电路**（DW01A + FS8205A 或一体保护板）——
无保护板版本**退换**（硬约束：锂电池无二级保护不可装机）；容量档 3000–5000mAh
（1S 3.7V 标称），低于 3000mAh 不满足整机续航与舵机堵转裕量。

- 操作步骤：
  1. 充电截止核对：完整充一次，红灯灭时万用表量电池端 ≈4.20V（>4.25V 判保护异常）；
  2. 放电截止核对：带载放电至保护板断开输出，量电池端 ≈2.4–2.5V（过放阈值）；
  3. 短路保护核对：输出端正负瞬接（打火即断输出），撤除负载后输出自恢复；
  4. 容量核对：以 0.5A 恒流放电时长估算容量 ≈ 标称档（粗核，防虚标档位）。
- 预期输出：三保护（过充 4.20V / 过放 ~2.45V / 短路断出）全部触发正常。
- 判定标准：保护板三功能在；容量落 3000–5000mAh 档；电池组输入范围覆盖 3.0–4.2V。
- 失败处置：无保护板 / 过充超 4.25V / 过放深于 2.3V 才断 → **退换货口径**（硬约束）；
  容量虚标严重（实测 <70% 标称）→ 换供应商并登记差异。

## 件5｜INA219 ADC 分压板（BOM #5，I2C 0x40）

**到货复核**：模块地址跳线缺省 0x40；与 §5.5.2 接线 3 分压网参数一致（1% 精度电阻）。
软件侧后端已收官（rr-hal `linux_power.rs`，INA219 I2C 后端，`8f4d928`）；键位
`RR3_HAL_I2C_BUS` / `RR3_HAL_INA219_ADDR`（缺省见 rr-hal `backend.rs`，以代码为准）。

- 操作步骤：
  1. 按 §5.5.2 接线 3 装配后 `i2cdetect -y 1`：0x40 在表（地址错位查 A0/A1 跳线）；
  2. **两点标定**：万用表并联电池母线，取两个工况点读数——满电静置（~4.15V）与
     带载（点亮 MAX7219 + 舵机摆动，~3.85V）；每点同时读万用表值 `V_meter` 与
     HAL 后端读数 `V_hal`；
  3. 偏差 = |V_hal − V_meter| / V_meter，逐点计算。
- 预期输出：两点偏差均 ≤2%（0.0.6 判据 12 口径：万用表两点标定偏差 ≤2% 才判过）。
- 判定标准：两点偏差 ≤2%；电流/功率读数符号与充放状态一致（充电为正/放电方向与
  采样端子定义一致，方向反则对调 VIN+/VIN− 接线）。
- 失败处置：超差 → 分压比复核（(R1+R2)/R2 与软件换算一致）+ INA219 校准寄存器复核；
  NACK → 地址/上拉/共地逐查；读数冻结 → 总线时钟被其他 I2C 件拖住的检查
  （GPIO2/3 上只挂 I2C 件，软件 PWM 不得复用，洞K 补行）。

## 件6｜ESP32 UART2 链路（0.0.7 批C④ 前置，CP2102 适配器）

**接线四件套**（硬约束，装配即核对）：ESP32 **GPIO17(TX2) → 适配器 RXD**、
**GPIO16(RX2) ← 适配器 TXD**、**GND 共地**、**全链 3.3V TTL——适配器 +5V/3V3 引脚
一律悬空不接**（ESP32 走自身 Type-C 独立供电；5V 接触任何 ESP32 GPIO 即毁）。

- 操作步骤：
  1. 适配器插 Mac，`ls /dev/cu.*` 出 `cu.usbserial-*`（CP2102 免驱）；
  2. 按 0.0.7 方案批C④ 口径烧录 esp32-uart-echo 固件（espflash，放活码见 0.0.7 §9）；
  3. round-trip：宿主侧经 rrd UART transport 发帧，echo 固件回环；
  4. 坏帧注入：短帧/坏 CRC/坏 magic 各注入一帧，验证拒收计数与链路不挂死。
- 预期输出：round-trip 帧逐字节一致；坏帧全部拒收、好帧不受牵连。
- 判定标准：批C④ 判据（round-trip + 坏帧注入双过，见 0.0.7 §9 对应节）。
- 失败处置：全 0/乱码 → 波特率 115200 与电平（3.3V）核对；无回显 → TX/RX 交叉
  核对（最常见的装配错误就是忘交叉）；时通时断 → GND 共地检查；Mac 不出设备 →
  换线（部分线材只供电无数据）。
