# 供给自证表（模板）

> 定性（[architecture.md](../architecture/architecture.md) §12.6 ③ 列，v0.9）：**装载门，
> 非行为证据**——这张表只证"描述符没撒谎"（声明的平台供给与载体实际供给逐键一致），
> **不证 port 正确**。运行期实测（时序直方图、断电恢复、看门狗复位、外设真信号）归
> 点验矩阵 ⑦ 列 / E4 真板，不得由本表冒领。

## 表从哪来、门在哪

- **声明值**的唯一数据事实源 = 装配单 `profiles/<机型>.toml` 的 `[supplies]`（watchdog 三键
  + 时序预算三键，ADR-0018 修订 4 ② / 修订 2 ③）与 `[os]`/`[platform]`（route/tier）。
  本表"声明值"列一律照抄描述符并注明文件名，**不手填第二份**。
- **核对门** = rrd 装载链 `rr3_profile_boot_inputs`（查册门 + 形状门 + G6 档位↔watchdog
  一致性 + L-10 tier↔tier_scope）——描述符撒谎（键缺失/坏值/档位与 watchdog 不符）在
  boot 即拒，逐条点名。
- **本表** = port 移植者对每个键交的核对行：声明值 × 载体事实/实测值 × 证据 × 环境。
  行 = 一块板/一档；跑不到的格写"未实测 + 触发条件"，不留白、不拿"设计已覆盖"充数。

| 供给类 | 表内对应键 | 核对口径 |
|---|---|---|
| 时基 | `tick_period_ms` / `tick_jitter_ms` | 分辨率与是否单调（host: `CLOCK_MONOTONIC`；rtos: FreeRTOS tick/`esp_timer`；bare: 硬件定时器） |
| 内存 | （随 tier 定性） | 内存模型：host=进程堆；rtos=RTOS 堆/任务栈；bare=静态分配/池——机制核无全局分配器假设（裁定 3） |
| 事件循环 | `watchdog_feeder` + `tick_*` | 循环形态：host=rrd tick 环喂 watchdog；rtos/bare=rr-core::runtime 运行环自喂（板侧无 rrd）；无 WDT 不得归 bare 档（只能 rtos + 外部监督） |
| 传输 | （[hardware]/桥，随形态） | 是否保消息边界：uds/shm 面向数据报；UART 走帧化（0.0.7 批D rr3-bridge） |

## 判据

1. 与描述符**逐键核对，不一致即红**（§12.6 ③ 列判据原文）；
2. 行缺 = 描述符谎报（声明了供给却没交核对行），同红；
3. "载体事实/实测值"列：E1/E2/E3 标准环境只能填装载门数值面；**运行期实测只有 E4 真板能填**
   （云 runner 是共享 x86、qemu-user 是指令级模拟，时间不是硬件时间）；
4. 实测值必须随行给证据（[matrix.sh](../../tools/ci/matrix.sh) `--manual <列号> --evidence
   <仓内证据文件>` 回填）：证据文件三样——**环境指纹**（设备/固件版本 + `rustc -Vv` +
   目标三元组）、**采样窗口与样本数**、**原始数据**（周期直方图或日志切片），缺一判
   "证据不足"不判 PASS；
5. "未实测 + 触发条件"是合法行；"声明值冒充实测值"不是。

## 填写示例（esp32-mini 第二形态，首行样张）

装配单：[esp32-mini.toml](../../profiles/esp32-mini.toml)（0.0.5 批K C2 裁剪件——件码零改动、
对外主题零改动、装配自洽三判据见其头注释）。

| 键 | 声明值 | 载体事实/实测值 | 证据 | 环境（指纹） |
|---|---|---|---|---|
| `platform.tier` | `rtos` | ESP32-S3 + ESP-IDF（FreeRTOS） | 装载门：`rr3_profile_boot_inputs` 过（rtos 档） | E3 espidf-std（指纹随行） |
| `watchdog_present` | `true` | 板侧 WDT 由 rr-core::runtime 运行环喂（feeder=`rr-core`，板侧无 rrd） | 装载门 G6 过；喂拍实测未做 | E3（数值面） |
| `watchdog_timeout_ms` | `15000` | **未实测**——宽于模块级 10000 的平台兜底，复位行为待真板 | —— | 触发条件：0.0.7 真板 |
| `tick_period_ms` | `200` | **未实测**——声明预算位，对账归 0.0.7 点验矩阵行 | —— | 触发条件：0.0.7 真板 |
| `tick_jitter_ms` | `100` | **未实测**（同上） | —— | 触发条件：0.0.7 真板 |
| `safety_core_interval_ms` | `1000` | **未实测**（同上） | —— | 触发条件：0.0.7 真板 |

上表即 ③ 列"port 交一张表"的形状：声明列与 `[supplies]` 逐键同源，实测列诚实分档
（装载门已核 / E4 待测），⑦ 列直方图到位后回填并走 `--manual` 契约留痕。
