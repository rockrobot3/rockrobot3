- 命名矩阵（`docs/naming.md`，逐字）：模块目录/crate/进程/bin = `rr3-<域>`；基座内部 crate = `rr-<设施名>`（无 3）；Rust lib target 连字符转下划线（`rr-ipc` → `rr_ipc`）；跨 crate 导出自由函数 = `rr3_<域>_<动作>`；导出类型 = `Rr3` 前缀；trait = `Rr3` 前缀且方法不加前缀；crate 内私有函数不加前缀

## 演进规则（ADR-0007 决策二）

1. **只增不改**：既有字段、偏移、枚举值不得变更语义
2. 破坏性变更必须升 `schema.version` major，并在 `topics.toml` 登记受影响主题
3. 消息头扩展**只允许写 reserved 区**并经 `flags` 标记启用（保持与 A-IPC 标准逐字节兼容）
4. CI 三检查在 PR 上强制：workspace 编译 / manifest schema 校验 / 主题前缀归属

## 标准歧义登记（每半年随 ADR-0004 复查核对）

- **magic 的字节序**：A-IPC 标准 §2.2/§2.3 以 C 语义声明 `magic` **字段值**为 `0x41524531`
  并规定所有多字节字段小端序（AOS-STD-IPC-003/020，L1 稳定级），据此线上字节为
  `31 45 52 41`；而同一文档的注释 `'A''R''E''1'` 与 §7.2 Wireshark 伪代码
  `buffer(0,4):uint()`（大端读）给出 `41 52 45 31`。两处结论相反。
  **rock3 采规范条目（L1）为准：字段值 0x41524531，LE 存储，线上字节 31 45 52 41。**
  理由是与真实 C 实现互通（`hdr.magic = AIRY_IPC_MAGIC` 在小端机落地即此字节序），
  而非与 ASCII 注释互通。若标准维护方认定注释为准，本文件、`envelope.schema.json`
  与 `golden/*.hex` 一起升 major。
- **payload type 前缀占几字节**：标准 §7.2/§7.3 说"payload 类型由 payload 体首字段携带"，
  但 §3.2–3.6 的 C 结构体首字段分别是 `request_id`/`event_id`/`stream_id`，未写清该前缀
  的宽度与对齐。**v0.0.1 只冻结 128B 头与 5 个 payload 类型枚举值，payload 视为不透明
  JSON 字节**；前缀编码留 M2 决策（届时同步影响 IPC-T-004 的 golden 向量）。

    pub const RECV: u16 = 0x0002;
    pub const SEND_BATCH: u16 = 0x0003;
    pub const CANCEL: u16 = 0x0004;

/// 头 flags 位。标准定义的全部 8 位；rock3 采用 NOWAIT/SIGNAL/ZEROCOPY/URGENT/NOREPLY，
/// CAP_CARRY/COMPRESS/ENCRYPT 已定义但不使用（ADR-0006 备选否决项）。
pub mod flags {
    pub const NOWAIT: u16 = 0x0001;
    pub const SIGNAL: u16 = 0x0002;
    pub const ZEROCOPY: u16 = 0x0004;
    pub const CAP_CARRY: u16 = 0x0008;
    pub const COMPRESS: u16 = 0x0010;
    pub const ENCRYPT: u16 = 0x0020;
    pub const URGENT: u16 = 0x0040;
    pub const NOREPLY: u16 = 0x0080;

    /// 标准已定义位掩码：发送方不得置位掩码之外的位（AOS-STD-IPC-004）；
    /// 接收方对掩码之外的位必须忽略而非报错（前向兼容），见 `Rr3Header::from_bytes`。
    pub const DEFINED: u16 = NOWAIT
        | SIGNAL
        | ZEROCOPY
        | CAP_CARRY
        | COMPRESS
        | ENCRYPT
        | URGENT
        | NOREPLY;
}

/// 5 种 payload 类型，枚举值 L1 永久稳定（AOS-STD-IPC-005）
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Rr3PayloadType {
    /// RPC 调用（JSON-RPC 2.0 body）
    Request = 0x0001,
    /// RPC 响应
    Response = 0x0002,
    /// 事件总线，尽力投递
    Event = 0x0003,
    /// 有序流：音频 PCM / 关节状态（实时控制面）
    Stream = 0x0004,
    /// 心跳 / 系统通知
    Notification = 0x0005,
}

impl Rr3PayloadType {
    /// 由类型枚举值解析。payload 体首字节的取法留 M2（payload 前缀宽度未冻结）。
    pub fn from_u16(v: u16) -> Option<Self> {
        match v {
            0x0001 => Some(Self::Request),
            0x0002 => Some(Self::Response),
            0x0003 => Some(Self::Event),
            0x0004 => Some(Self::Stream),
            0x0005 => Some(Self::Notification),
            _ => None,
        }
    }
}

/// RESPONSE.status —— AIRY_E* 子集（ADR-0006 §3）
#[derive(Debug, Clone, Copy, PartialEq, Eq)]

    Ok = 0,

    Busy = -16,
    Permission = -22,
    TimedOut = -1004,
}

    pub flags: u16,
    pub trace_id: u64,
    pub timestamp_ns: u64,
    pub src_task: u64,
    pub dst_task: u64,

impl Rr3Header {
    /// 广播目标（dst_task = 0，标准不为其设独立标志位）

            opcode,
            flags: 0,
            trace_id: 0,

            src_task: 0,
            dst_task: 0,

    }

    /// 解析 128 字节头（小端）。IPC-T-001/002/010。
    pub fn from_bytes(buf: &[u8]) -> Result<Self, Rr3HdrError> {
        if buf.len() < RR3_IPC_HDR_SIZE {
            return Err(Rr3HdrError::TooShort { got: buf.len() });
        }
        let u16le = |o: usize| u16::from_le_bytes(buf[o..o + 2].try_into().unwrap());
        let u32le = |o: usize| u32::from_le_bytes(buf[o..o + 4].try_into().unwrap());
        let u64le = |o: usize| u64::from_le_bytes(buf[o..o + 8].try_into().unwrap());

        let magic = u32le(OFF_MAGIC);
        if magic != MAGIC {
            return Err(Rr3HdrError::BadMagic { got: magic });
        }
        if buf[OFF_RESERVED..OFF_RESERVED + LEN_RESERVED]
            .iter()
            .any(|&b| b != 0)
        {
            return Err(Rr3HdrError::ReservedNotZero);
        }
        let payload_len = u32le(OFF_PAYLOAD_LEN);
        if payload_len > MAX_PAYLOAD_LEN {
            return Err(Rr3HdrError::PayloadTooLarge { len: payload_len });
        }
        Ok(Self {
            opcode: u16le(OFF_OPCODE),
            // 未知 flags 位原样保留、不报错：AOS-STD-IPC-004 要求接收方忽略未知位
            flags: u16le(OFF_FLAGS),
            trace_id: u64le(OFF_TRACE_ID),
            timestamp_ns: u64le(OFF_TIMESTAMP_NS),
            src_task: u64le(OFF_SRC_TASK),
            dst_task: u64le(OFF_DST_TASK),
            payload_len,
        })
    }

    /// 编码为 128 字节（reserved 自动全 0）。
    pub fn to_bytes(&self) -> [u8; RR3_IPC_HDR_SIZE] {
        let mut buf = [0u8; RR3_IPC_HDR_SIZE];
        buf[OFF_MAGIC..OFF_MAGIC + LEN_MAGIC].copy_from_slice(&MAGIC.to_le_bytes());
        buf[OFF_OPCODE..OFF_OPCODE + LEN_OPCODE].copy_from_slice(&self.opcode.to_le_bytes());
        buf[OFF_FLAGS..OFF_FLAGS + LEN_FLAGS].copy_from_slice(&self.flags.to_le_bytes());
        buf[OFF_TRACE_ID..OFF_TRACE_ID + LEN_TRACE_ID].copy_from_slice(&self.trace_id.to_le_bytes());
        buf[OFF_TIMESTAMP_NS..OFF_TIMESTAMP_NS + LEN_TIMESTAMP_NS]
            .copy_from_slice(&self.timestamp_ns.to_le_bytes());
        buf[OFF_SRC_TASK..OFF_SRC_TASK + LEN_SRC_TASK].copy_from_slice(&self.src_task.to_le_bytes());
        buf[OFF_DST_TASK..OFF_DST_TASK + LEN_DST_TASK].copy_from_slice(&self.dst_task.to_le_bytes());
        buf[OFF_PAYLOAD_LEN..OFF_PAYLOAD_LEN + LEN_PAYLOAD_LEN]
            .copy_from_slice(&self.payload_len.to_le_bytes());
        buf
    }
}

- Modify: `contracts/README.md`（Task 1 占位 → 本任务补最终说明）

**Interfaces:**
- Consumes: Task 3 的 payload 类型语义（REQUEST/RESPONSE/EVENT/STREAM/NOTIFICATION）

**裁定（写进 contracts/README.md）**

1. 主题字符串**不进 128B 消息头**（ADR-0006 §2：topic 置于 payload 内）。本文件是"谁有权发布什么"的**离线注册表**，运行时用于校验与文档生成，不参与线格式。
2. 规范形式：`<owner>/<域>/<事件>`，三段。`owner` 必须等于某个模块的 `[manifest].name`（方案 §4：`^rr3-[a-z]+$`，**词干只许小写字母**，不含数字与连字符）；域与事件段用小写字母 + 下划线（`^[a-z_]+$`，与 capability 段同规则）。**逐条列举而非正则通配**，是为了让"新增主题必须改契约文件"成为显式动作（改契约 = 走 review）。
3. 每个 topic 的 owner **必须**在 `[[owner]]` 中登记；一个 topic 只有一个 owner（发布方唯一），订阅方可多个。
4. `kind` 取值 `request|event|stream|notification`，与 A-IPC payload 类型一一对应（request 表示 REQUEST+RESPONSE 往返）。STREAM 类主题即 ADR-0007 的实时控制面候选，v0.0.1 仅登记、不实现传输。

use toml::Value;

/// manifest 契约 schema 版本（与 contracts/schema_version 同步）
pub const RR3_MANIFEST_SCHEMA_VERSION: u32 = 1;

const RR3_MODULE_SCHEMA_TOML: &str = include_str!("module.schema.toml");

/// 单个 manifest 字段的契约描述
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Rr3FieldSpec {
    pub path: String,
    pub kind: String,
    pub required: bool,
    pub rule: Option<String>,
}

fn rr3_registry_str_field(table: &toml::Table, key: &str) -> Option<String> {
    table.get(key).and_then(Value::as_str).map(str::to_string)
}

/// 解析内嵌 schema，返回字段规格列表（顺序与契约文件一致）
pub fn rr3_registry_field_specs() -> Vec<Rr3FieldSpec> {
    let root: Value = toml::from_str(RR3_MODULE_SCHEMA_TOML)
        .unwrap_or_else(|e| panic!("module.schema.toml 解析失败: {e}"));
    let fields = root
        .get("field")
        .and_then(Value::as_array)
        .unwrap_or_else(|| panic!("module.schema.toml 缺少 [[field]] 数组"));
    fields
        .iter()
        .filter_map(Value::as_table)
        .map(|f| Rr3FieldSpec {
            path: rr3_registry_str_field(f, "path").expect("field.path 必填"),
            kind: rr3_registry_str_field(f, "kind").expect("field.kind 必填"),
            required: f.get("required").and_then(Value::as_bool).unwrap_or(false),
            rule: rr3_registry_str_field(f, "rule"),
        })
        .collect()
}

    let arr = root.get("rules")?.get(name)?.as_array()?;

```rust
//! manifest / topics 校验。规则语义全部来自 `module.schema.toml` 的 `[rules]`。
//!
//! 规则清单（方案 §4 表格逐行落地）：
//! - `module_name`：`^rr3-[a-z]+$`
//! - `semver`：点分数字
//! - `type` / `lang` / `restart_policy`：枚举，取自 `[rules]`
//! - `capability`：`^[a-z]+(\.[a-z_]+)+$`
//! - `topic`：`rr3-<模块>/<域>/<事件>`
//! - `own_topic`：先过 `topic`，再要求前缀等于本 manifest 的 `manifest.name`
//! - `none`：放行

use std::path::{Path, PathBuf};
use toml::Value;

use crate::schema::{
    rr3_registry_field_specs, rr3_registry_get_by_path, rr3_registry_rule_list,
};

const RR3_TOPIC_HEAD: &str = "rr3-";

/// 一次 manifest 校验的结果
#[derive(Debug, Default)]
pub struct Rr3ValidationReport {
    pub errors: Vec<String>,
}

impl Rr3ValidationReport {
    pub fn ok(&self) -> bool {
        self.errors.is_empty()
    }
}

/// 小写段（`[a-z]+`）：manifest.name 去前缀后的部分
fn rr3_registry_lower_alpha(s: &str) -> bool {
    !s.is_empty() && s.chars().all(|c| c.is_ascii_lowercase())
}

/// capability 段：小写字母 + 下划线，非空
fn rr3_registry_lower_us(s: &str) -> bool {
    !s.is_empty() && s.chars().all(|c| c.is_ascii_lowercase() || c == '_')
}

/// `^[a-z]+(\.[a-z_]+)+$`
fn rr3_registry_capability_shape(s: &str) -> bool {
    let segs: Vec<&str> = s.split('.').collect();
    segs.len() >= 2 && segs.iter().all(|s| rr3_registry_lower_us(s))
}

/// `rr3-<模块>/<域>/<事件>`，三段；首段带 rr3- 前缀
fn rr3_registry_topic_shape_ok(name: &str) -> bool {
    let segs: Vec<&str> = name.split('/').collect();
    if segs.len() != 3 || !segs[0].starts_with(RR3_TOPIC_HEAD) {
        return false;
    }
    let stem = &segs[0][RR3_TOPIC_HEAD.len()..];
    rr3_registry_lower_alpha(stem)
        && segs[1..].iter().all(|s| rr3_registry_lower_us(s))
}

/// 点分数字版本
fn rr3_registry_semver_ok(s: &str) -> bool {
    s.contains('.')
        && !s.starts_with('.')
        && !s.ends_with('.')
        && s.split('.').all(|p| !p.is_empty() && p.chars().all(|c| c.is_ascii_digit()))
}

/// 单条规则检查（上下无关规则）。`own_topic` 需 manifest.name，由
/// `rr3_registry_validate_manifest` 特判，不进这里。
pub fn rr3_registry_check(rule: &str, value: &str) -> Vec<String> {
    let bad = |m: String| vec![m];
    match rule {
        "none" => vec![],
        "module_name" => {
            let stem = value.strip_prefix(RR3_TOPIC_HEAD).unwrap_or("");
            if rr3_registry_lower_alpha(stem) {
                vec![]
            } else {
                bad(format!("manifest.name 非法: {value}（要求 ^rr3-[a-z]+$）"))
            }
        }
        "semver" => {
            if rr3_registry_semver_ok(value) {
                vec![]
            } else {
                bad(format!("semver 非法: {value}（要求点分数字）"))
            }
        }
        "type" | "lang" | "restart_policy" => {
            let allowed = rr3_registry_rule_list(rule).unwrap_or_default();
            if allowed.iter().any(|a| a == value) {
                vec![]
            } else {
                bad(format!("{rule} 越界: {value}（允许 {allowed:?}）"))
            }
        }
        "capability" => {
            if rr3_registry_capability_shape(value) {
                vec![]
            } else {
                bad(format!("capability 非法: {value}（要求 ^[a-z]+(\\.[a-z_]+)+$）"))
            }
        }
        "topic" => {
            if rr3_registry_topic_shape_ok(value) {
                vec![]
            } else {
                bad(format!("topic 非法: {value}（要求 rr3-<模块>/<域>/<事件>）"))
            }
        }
        other => bad(format!("未知规则名（schema 与代码不同步）: {other}")),
    }
}

fn rr3_registry_type_err(path: &str, kind: &str, v: &Value) -> String {
    format!("字段 {path} 类型应为 {kind}，实际为 {v:?}")
}

/// 从 manifest 路径向上定位 `contracts/topics.toml`
fn rr3_registry_contract_path(manifest: &Path) -> PathBuf {
    manifest
        .ancestors()
        .find(|a| a.join("contracts/topics.toml").is_file())
        .map(|root| root.join("contracts/topics.toml"))
        .unwrap_or_else(|| PathBuf::from("contracts/topics.toml"))
}

/// 校验单个 module.toml（含与 contracts/topics.toml 的交叉校验）
pub fn rr3_registry_validate_manifest(path: &Path) -> Rr3ValidationReport {
    let mut report = Rr3ValidationReport::default();

    let text = match std::fs::read_to_string(path) {
        Ok(t) => t,
        Err(e) => {
            report.errors.push(format!("无法读取 manifest {}: {e}", path.display()));
            return report;
        }
    };
    let root: Value = match toml::from_str(&text) {
        Ok(v) => v,
        Err(e) => {
            report.errors.push(format!("manifest TOML 解析失败: {e}"));
            return report;
        }
    };

    let self_name = rr3_registry_get_by_path(&root, "manifest.name")
        .and_then(Value::as_str)
        .unwrap_or("");
    let contract_path = rr3_registry_contract_path(path);
    let contract_text = std::fs::read_to_string(&contract_path);
    let registered: Vec<String> = match &contract_text {
        Ok(t) => crate::validate::rr3_registry_topic_names(t),
        Err(_) => {
            report.errors.push(format!(
                "无法读取主题契约 {}（manifest 交叉校验需要它）",
                contract_path.display()
            ));
            vec![]
        }
    };

    // 1) 逐字段：存在性 + 类型 + 规则
    for spec in rr3_registry_field_specs() {
        let found = rr3_registry_get_by_path(&root, &spec.path);
        let Some(value) = found else {
            if spec.required {
                report.errors.push(format!("缺少必填字段 {}", spec.path));
            }
            continue;
        };

        let kind_ok = match spec.kind.as_str() {
            "string" => match value.as_str() {
                Some(s) => {
                    if let Some(rule) = &spec.rule {
                        report.errors.extend(rr3_registry_check(rule, s));
                    }
                    true
                }
                None => false,
            },
            "bool" => value.as_bool().is_some(),
            "int" => value.as_integer().is_some(),
            "list" => match (value.as_array(), spec.rule.as_deref()) {
                (Some(arr), Some(rule)) => {
                    for item in arr.iter().filter_map(Value::as_str) {
                        if rule == "own_topic" {
                            report.errors.extend(rr3_registry_check("topic", item));
                            let want = format!("{self_name}/");
                            if !self_name.is_empty() && !item.starts_with(&want) {
                                report.errors.push(format!(
                                    "越权主题 {item}（前缀必须是 {want}）"
                                ));
                            }
                            if !registered.is_empty()
                                && !registered.iter().any(|t| t == item)
                            {
                                report.errors.push(format!("未注册主题 {item}"));
                            }
                        } else {
                            report.errors.extend(rr3_registry_check(rule, item));
                        }
                    }
                    true
                }
                (Some(_), None) => true,
                _ => false,
            },
            other => panic!("schema 未知 kind {other}（契约与代码不同步）"),
        };
        if !kind_ok {
            report.errors.push(rr3_registry_type_err(&spec.path, &spec.kind, value));
        }
    }

    // 2) 跨字段：heartbeat < watchdog（方案 §4 [health] 约束）
    let hb = rr3_registry_get_by_path(&root, "health.heartbeat_ms").and_then(Value::as_integer);
    let wd = rr3_registry_get_by_path(&root, "health.watchdog_timeout_ms")
        .and_then(Value::as_integer);
    if let (Some(hb), Some(wd)) = (hb, wd) {
        if hb >= wd {
            report.errors.push(format!("heartbeat_ms({hb}) 必须小于 watchdog_timeout_ms({wd})"));
        }
    }

    // 3) 依赖必须命中 base 内建能力（v0.0.1 无跨模块能力注册表）
    let base = rr3_registry_rule_list("base_capabilities").unwrap_or_default();
    for field in ["depends.required", "depends.optional"] {
        if let Some(arr) = rr3_registry_get_by_path(&root, field).and_then(Value::as_array) {
            for cap in arr.iter().filter_map(Value::as_str) {
                if !base.iter().any(|b| b == cap) {
                    report.errors.push(format!("{field} 依赖了未知能力 {cap}"));
                }
            }
        }
    }

    // 4) subscribes 必须已注册（订阅方不要求前缀归属）
    if !registered.is_empty() {
        if let Some(arr) = rr3_registry_get_by_path(&root, "events.subscribes")
            .and_then(Value::as_array)
        {
            for topic in arr.iter().filter_map(Value::as_str) {
                if !registered.iter().any(|t| t == topic) {
                    report.errors.push(format!("events.subscribes 引用未注册主题 {topic}"));
                }
            }
        }
    }

    report
}

/// 取 topics.toml 中登记的 owner 名列表
pub fn rr3_registry_topic_owners(text: &str) -> Vec<String> {
    match toml::from_str::<Value>(text) {
        Ok(root) => owner_names_in(&root),
        Err(_) => vec![],
    }
}

fn owner_names_in(root: &Value) -> Vec<String> {
    table_field_strings(root, "owner", "name")
}

/// 取 topics.toml 中登记的 topic 名列表
pub fn rr3_registry_topic_names(text: &str) -> Vec<String> {
    match toml::from_str::<Value>(text) {
        Ok(root) => table_field_strings(&root, "topic", "name"),
        Err(_) => vec![],
    }
}

fn table_field_strings(root: &Value, array_key: &str, field: &str) -> Vec<String> {
    root.get(array_key)
        .and_then(Value::as_array)
        .map(|arr| {
            arr.iter()
                .filter_map(Value::as_table)
                .filter_map(|t| t.get(field).and_then(Value::as_str))
                .map(str::to_string)
                .collect()
        })
        .unwrap_or_default()
}

/// 校验一段 topics.toml 文本：owner 必须登记、topic 必须以 "<owner>/" 开头、kind 必须合法
pub fn rr3_registry_validate_topics(text: &str, known_owners: &[String]) -> Vec<String> {
    let mut errs = vec![];
    let Ok(root) = toml::from_str::<Value>(text) else {
        return vec!["topics.toml 解析失败".to_string()];
    };
    let allowed_kinds = rr3_registry_rule_list("topic_allowed_kinds").unwrap_or_default();
    let declared_owners = owner_names_in(&root);

    for entry in root.get("topic").and_then(Value::as_array).into_iter().flatten() {
        let Some(t) = entry.as_table() else { continue };
        let Some(name) = t.get("name").and_then(Value::as_str) else {
            errs.push("topic 缺少 name".to_string());
            continue;
        };
        let owner = t.get("owner").and_then(Value::as_str).unwrap_or("");
        let kind = t.get("kind").and_then(Value::as_str).unwrap_or("");

        errs.extend(rr3_registry_check("topic", name));
        if !known_owners.iter().any(|o| o == owner) && !declared_owners.iter().any(|o| o == owner)
        {
            errs.push(format!("topic {name} 的 owner 未登记: {owner}"));
        } else if !name.starts_with(&format!("{owner}/")) {
            errs.push(format!("topic {name} 不在 owner {owner} 命名空间内"));
        }
        if !allowed_kinds.iter().any(|k| k == kind) {
            errs.push(format!("topic {name} 的 kind 非法: {kind}"));
        }
    }
    errs
}

//! # rr3-mkmod
//!
//! 生成 `modules/rr3-<名>/` 骨架：manifest + config + 空 Rust 程序 + README。
//! 生成物当场用 `rr-registry` 的契约校验，不合规即中止（architecture.md §7）。

use std::path::{Path, PathBuf};

#[derive(Debug)]
pub enum Rr3MkmodError {
    InvalidName(String),
    AlreadyExists(PathBuf),
    Io(std::io::Error),
    Manifest(Vec<String>),
}

impl From<std::io::Error> for Rr3MkmodError {
    fn from(e: std::io::Error) -> Self {
        Self::Io(e)
    }
}

impl std::fmt::Display for Rr3MkmodError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::InvalidName(n) => write!(f, "模块名非法: {n}（要求 rr3-[a-z][a-z0-9-]*）"),
            Self::AlreadyExists(p) => write!(f, "目录已存在: {}", p.display()),
            Self::Io(e) => write!(f, "IO 失败: {e}"),
            Self::Manifest(errs) => write!(f, "生成的 manifest 不合规:\n  {}", errs.join("\n  ")),
        }
    }
}

const RR3_NAME_HEAD: &str = "rr3-";

/// 归一化：允许 `audio` 或 `rr3-audio`，产出 `rr3-audio`
/// 词干必须匹配方案 §4 的 `^rr3-[a-z]+$`（小写字母，不含数字/连字符），长度 2..=24
fn rr3_mkmod_stem(name: &str) -> Result<String, Rr3MkmodError> {
    let stem = name.strip_prefix(RR3_NAME_HEAD).unwrap_or(name);
    let ok = stem.len() >= 2
        && stem.len() <= 24
        && stem.chars().all(|c| c.is_ascii_lowercase());
    if !ok {
        return Err(Rr3MkmodError::InvalidName(name.to_string()));
    }
    Ok(format!("{RR3_NAME_HEAD}{stem}"))
}

/// 在 `out_root` 下生成 `<id>/` 全套骨架；返回生成的文件列表（绝对路径）
pub fn rr3_mkmod_generate(name: &str, out_root: &Path) -> Result<Vec<PathBuf>, Rr3MkmodError> {
    let id = rr3_mkmod_stem(name)?;
    let target = out_root.join(&id);
    if target.exists() {
        return Err(Rr3MkmodError::AlreadyExists(target));
    }

    // 先写临时目录，manifest 校验通过后再 rename，避免留下半成品模块
    let staging = out_root.join(format!(".staging-{id}"));
    let _ = std::fs::remove_dir_all(&staging);
    std::fs::create_dir_all(staging.join("src"))?;

    let files: Vec<(&str, String)> = vec![
        ("module.toml", module_toml(&id)),
        ("config.toml", config_toml(&id)),
        ("Cargo.toml", crate_toml(&id)),
        ("src/main.rs", main_rs(&id)),
        ("README.md", readme(&id)),
    ];
    for (rel, body) in &files {
        let path = staging.join(rel.to_string());
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(&path, body)?;
    }

    let report = rr_registry::rr3_registry_validate_manifest(&staging.join("module.toml"));
    if !report.ok() {
        let _ = std::fs::remove_dir_all(&staging);
        return Err(Rr3MkmodError::Manifest(report.errors));
    }

    std::fs::rename(&staging, &target)?;
    Ok(files.iter().map(|(rel, _)| target.join(rel.to_string())).collect())
}
```

use std::path::PathBuf;

fn usage() -> ! {
    eprintln!("用法: rr3-mkmod <模块名> [输出根目录，默认 ./modules]");
    eprintln!("示例: rr3-mkmod rr3-arm");
    std::process::exit(2);
}

fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    if args.is_empty() || args.len() > 2 || args[0] == "-h" || args[0] == "--help" {
        usage();
    }
    let out_root = PathBuf::from(args.get(1).map(String::as_str).unwrap_or("modules"));
    if let Err(e) = std::fs::create_dir_all(&out_root) {
        eprintln!("无法创建输出根目录 {}: {e}", out_root.display());
        std::process::exit(1);
    }

    match rr3_mkmod::rr3_mkmod_generate(&args[0], &out_root) {
        Ok(files) => {
            println!("已生成模块骨架 ({} 个文件):", files.len());
            for f in files {
                println!("  {}", f.display());
            }
            println!("\n下一步：在 contracts/topics.toml 登记主题（见模块 README）");
        }
        Err(e) => {
            eprintln!("生成失败: {e}");
            std::process::exit(1);
        }
    }
}

    /// 时长（毫秒，向下取整）
    pub fn rr3_pcm_duration_ms(&self) -> u64 {
        if self.cfg.sample_rate_hz == 0 || self.cfg.channels == 0 {
            return 0;
        }
        let frames = self.samples.len() / self.cfg.channels as usize;
        frames as u64 * 1000 / self.cfg.sample_rate_hz as u64
    }
